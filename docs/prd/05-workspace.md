## 1. 하는 일

앱을 열면 처음 보이는 **사용자별 작업 공간**이다. 내가 만든 양식과 취합을 한눈에 보고, 다음 할 일(이번 주 기한, 아직 취합하지 않은 양식)을 바로 연다.

원칙: **앱이 실제로 아는 것만 보여 준다.**
회신 파일은 메신저·메일로 오고 앱은 취합할 때 처음 본다. 그래서 **취합하기 전에는 누가 냈는지 보여 주지 않는다.** 제출 현황(낸 곳·안 낸 곳)은 취합 기록에만 있다.

## 2. 화면

위에서 아래로:

| 영역 | 내용 |
|---|---|
| 인사 줄 | 오늘 날짜, "취합 기다리는 양식 N건 중 이번 주가 기한인 양식이 M건". 버튼 [AI로 만들기] [받은 파일 취합하기] [＋ 새 양식 만들기] |
| 숫자 4칸 | 취합 기다리는 양식 · 이번 주 제출 기한(이번 주 토요일까지) · 기한 지났는데 취합 전 · 이번 달 마친 취합 |
| 취합 일정 (달력) | 양식마다 **만든 날 → 제출 기한**을 한 줄 막대로. 시작에 ○(만든 날), 끝에 [기한]. 기한이 없으면 만든 날 하루짜리 막대. 취합한 날에 [✓ 취합]. 오늘은 파란 칸, 주말은 빗금. 이전/다음 달, [오늘]. 막대를 누르면 양식을 연다 |
| 취합 기다리는 양식 (오른쪽) | 기한 가까운 순, 기한 없는 양식은 뒤로. 카드: 제목, D-day(2일 이하 빨강, 지나면 D+n, 기한 없으면 "기한 없음"), 구조·제출처 수, 만든 날~기한 경과 막대(제출률 아님), "**취합 전** · 받은 파일을 넣으면 누가 냈는지 알려줘요", [받은 파일 취합하기] [양식 열기]. 기한이 없으면 [기한 넣기] |
| 탭: 내가 만든 양식 | 구조별로 골라 보기. 카드: 구조 그림, 제목, 제출처·버전·만든 날·기한, 상태(내보내기 전 / 취합 전 / M/D 취합함 · 모두 n번), 버튼(내보내기 전 → [이어서 고치기], 그 밖 → [열기] [취합하기], 오른쪽 끝 [삭제]). 맨 앞에 [새 양식 만들기] 카드 |
| 양식 삭제 | [삭제] → 확인 창 "양식을 지울까요?"(이미 보낸 엑셀 파일과 취합 이력은 그대로, .form.json이 있으면 다시 열 수 있음) → [삭제]. 클라우드는 `deleted_at` 표시만 남긴다(되살릴 수 있음). 지운 양식은 `removed-forms`에 표시해, AI 대화 카드에 남아 있어도 새로고침 때 패널이 다시 열어 자동 저장으로 되살리지 않는다. 같은 양식을 다시 저장하면 표시를 지운다. 지울 때 그 양식이 설정 패널에 열려 있으면 패널을 닫는다(`hanan-moa:form-removed`). 열린 채로 고치면 자동 저장으로 되살아나기 때문 |
| 탭: 취합 이력 | 전체 / 모두 받음 / 일부만 받음. 카드: 제목, 취합한 날·구조·버전·제출처 수, 제출(낸 수/목록 수)·모은 줄(시트 모으기형은 모은 시트)·확인한 칸, 안 낸 곳 이름(6곳까지 + 나머지 수) 또는 "✓ 모든 {제출처}에서 받았어요", 검산 불일치면 표시. [받은 파일로 다시 취합] [양식 열기] |

- 달력 막대와 오른쪽 카드는 마우스를 올리면 서로 테두리로 짚어 준다.
- 제출처를 부르는 말은 양식의 `org.label`을 따른다(지사·부서·담당자…). 식별 안 함이면 "파일". 세는 말은 담당자 → 명, 파일 → 개, 그 밖 → 곳.

## 3. 양식 상태 판단 (`src/workspace/plan.ts`)

| 상태 | 조건 | 어디에 보이나 |
|---|---|---|
| 내보내기 전 (`draft`) | `lastExported` 없음 | 내가 만든 양식만 (달력·기다리는 목록에는 안 보임) |
| 취합 기다림 (`waiting`) | 내보냈고, 마지막으로 내보낸 시각(`lastExported.updatedAt`) 이후 취합 기록이 없음 | 달력(색 막대), 기다리는 목록, 숫자 칸 |
| 취합함 (`done`) | 마지막으로 내보낸 뒤 취합 기록이 있음 | 달력(회색 막대 + ✓), 내가 만든 양식 |

- 같은 양식을 다시 내보내면(다음 분기 재요청 등) 다시 "취합 기다림"이 된다.
- 날짜는 그 지역 날짜 자정 기준: 만든 날 = `schema.createdAt`, 제출 기한 = `schema.deadline`(빌더 ① 기본 정보의 제출 기한).

## 4. 취합 기록 (요약만)

취합하기에서 **결과 파일을 내려받는 순간** 1건을 남긴다(`recordAggregation`). **결과 엑셀·받은 회신 파일·셀 값은 저장하지 않는다.**

| 칸 | 뜻 |
|---|---|
| `formId`, `formVersion`, `title`, `layout` | 어느 양식 |
| `unit` | 제출처를 부르는 말 (식별 안 함이면 '파일') |
| `total` | 제출처 목록 수 (목록이 없으면 없음) |
| `got` | 취합에 넣은 제출 수 |
| `missing` | 목록에 있는데 안 낸 곳 이름 |
| `rows` | 모은 줄 수 |
| `checked` | 확인한 칸 수 |
| `verifyOk` | 검산 일치 |
| `id`, `doneAt` | 기록 번호, 취합한 시각 |

저장 위치:
- **로컬 모드**(`npm run dev`, HTML 한 파일): 이 브라우저에만 (`hanan-moa:aggregations`, 최근 300건)
- **온라인 모드**(Vercel + Neon): 이 기기에 먼저 쓰고 Neon `public.moa_aggregations`에 올린다. 본인 행만 읽기·추가·삭제(RLS, 승인된 계정만). 못 올린 기록은 업무공간을 열 때 다시 올리고, 서버 기록으로 이 기기 목록을 맞춘다(다른 PC에서 한 취합도 보인다). 서버를 못 읽으면 "이 기기 기록만 보여요" 안내

## 5. 다른 화면으로 가기

화면 이동은 기존 이벤트를 쓴다.
- `hanan-moa:tab` `{ tab: 'ai' | 'aggregator', formId?, panel? }` — [받은 파일 취합하기]는 그 양식 `formId`를 넘겨, 취합하기가 그 양식을 기준 양식으로 잡는다. [새 양식 만들기]는 `{ tab: 'ai', panel: true }`로 AI로 만들기 화면의 오른쪽 설정 패널(빈 양식 만들기·양식 파일 열기)을 연다
- `hanan-moa:open-form` `{ schema, lastExported? }` — 양식 열기. AI로 만들기 화면의 오른쪽 설정 패널에 연다. 내보낸 기록을 같이 넘겨 버전 판단이 이어진다
