엑셀 취합 도우미

양식을 만들어 나눠 주고, 돌아온 엑셀 파일 여러 개를 넣으면 합쳐진 엑셀 한 개가 나오는 웹페이지입니다.

1왜 만드나요?

지금
  • 엑셀을 메일로 보내고, 돌아온 파일을 하나씩 열어 복사·붙여넣기
  • 사람마다 칸을 지우거나 순서를 바꿔서 보냄
  • 숫자 칸에 "약 10개" 같은 글자가 들어옴
  • 같은 파일을 고쳐서 또 보내면 어느 게 최신인지 헷갈림
  • 취합한 뒤 다시 보고서 모양으로 정리해야 함

나눠 준 양식 = 돌아온 취합본. 같은 틀을 끝까지 씁니다.

양식 파일과 취합본이 제목 위치, 칸 순서, 칸 이름, 색, 드롭다운까지 똑같습니다. 차이는 하나뿐입니다. 응답자 한 명분의 줄이 여러 명분으로 늘어나고, 오른쪽 끝에 "누가 냈는지" 칸이 붙습니다.

  • 정리할 필요 없음: 취합본을 받자마자 그대로 보고하거나 다음 작업에 씁니다. 칸 순서를 다시 맞출 일이 없습니다.
  • 기존 수식·보고서가 그대로 동작: "B열이 수량" 같은 위치가 양식과 취합본에서 똑같습니다.
  • 늦게 온 회신도 이어서: 취합본을 다시 넣고 새 회신 파일을 함께 넣으면 그 위에 이어 붙습니다. 처음부터 다시 할 필요가 없습니다.
  • 다음 차수에 다시 쓰기: 취합본 안에도 양식 정보가 들어 있어서, 취합본만 올려도 같은 양식을 되살릴 수 있습니다.

2기능 구성: 큰 기능 두 개

웹페이지는 위쪽 탭 두 개, 양식생성과 양식취합으로 나뉩니다. 두 기능을 가르는 경계는 메일 발송입니다.

판단 결과

두 기능으로 나누는 것이 적절합니다.

  • 업무 순서와 맞습니다. "보내기 전"과 "받은 뒤" 사이에 응답자가 입력하는 시간이 있어서, 실제 일도 이 지점에서 끊깁니다. 화면도 여기서 나누는 게 자연스럽습니다.
  • 남는 기능이 없습니다. 지금까지 정한 기능이 모두 둘 중 하나에 들어갑니다. "관리"나 "설정" 같은 세 번째 탭은 필요 없습니다.

대신 두 가지 조건을 지키며 만듭니다.

조건 1. 두 기능은 파일로만 이어집니다양식취합은 양식생성 화면에서 무엇을 했는지 몰라도 됩니다. 회신 파일 안에 양식 정보가 들어 있어서, 파일만 넣으면 어떤 양식인지 스스로 알아냅니다. 그래서 다른 PC나 며칠 뒤에도 회신 파일만 있으면 바로 취합할 수 있습니다.
조건 2. "같은 틀" 규칙은 한 번만 만듭니다빈 양식과 취합본을 각자 따로 만들면 언젠가 모양이 어긋납니다. 엑셀 모양을 만드는 부분을 두 기능이 함께 쓰게 해서, 두 파일이 항상 같은 틀이 되게 합니다.

3전체 흐름: 누가, 언제, 무엇을

세로 줄 세 개는 각각 나(관리자), 웹페이지, 응답자가 하는 일입니다. 위에서 아래로 따라가세요.

초록색 칸(①~⑤)이 웹페이지가 하는 일입니다. 나머지는 지금 하시는 일과 똑같습니다. 점선은 취합이 끝난 뒤 회신이 더 오면 이어서 합치는 길입니다.

5엑셀 파일은 이렇게 생깁니다: 양식과 취합본은 같은 틀

왜 "출처 파일" 칸을 맨 앞이 아니라 오른쪽 끝에 붙이나요?

맨 앞에 붙이면 양식의 칸이 한 칸씩 밀립니다. 그러면 "B열 = 수량"이 "D열 = 수량"으로 바뀌어서, 양식을 기준으로 만든 수식이나 보고서가 맞지 않게 됩니다. 오른쪽 끝에 붙이면 원래 칸 위치가 그대로 유지됩니다.

6합치는 원리: 사람처럼 꼼꼼하게

사람은 취합하면서 눈으로 보고 알아서 맞추는 일을 많이 합니다. 양식에서 조금 벗어난 파일도 사람만큼 다룰 수 있도록 아래 세 가지 원칙을 지킵니다.

🧮

한 줄도 잃어버리지 않는다

읽은 줄 수가 반영한 줄 + 뺀 줄과 같은지 매번 검산합니다. 뺀 줄은 이유와 함께 남깁니다.

✍️

고치되, 원래 값은 남긴다

확실한 것만 자동으로 고칩니다. 원래 값은 셀 메모로 남기고, 고친 칸은 파란색으로 표시합니다.

회신 파일 하나가 거치는 순서

초록색은 사람처럼 취합하기 위해 더한 단계, 회색은 기본 단계입니다. 오른쪽 끝 표시는 2번 기능 구성의 번호입니다.

읽는 범위: 인쇄영역 기준

응답자들은 인쇄영역 밖을 메모장처럼 씁니다. 그래서 인쇄영역 안만 데이터로 읽고, 밖에 적힌 글은 버리지 않고 "메모" 시트로 옮깁니다.

인쇄영역이 없는 파일은 지금처럼 제목 줄과 칸 모양을 보고 표를 찾습니다. 응답자가 인쇄영역을 지우거나 넓혀도, 표 바로 아래로 이어지는 줄은 묻지 않고 바로 넣습니다. 파일 이름 끝의 "(2)"는 같은 이름 첨부를 저장할 때 붙는 표시라 개정으로 보지 않습니다.

2순위

"생성일자"는 우리 양식에서 복사된 파일이라면 모두 같은 날짜(양식을 만든 날)로 찍혀 있어서 구별이 안 됩니다. 그래서 같은 파일 속 정보 중 마지막 저장 시각을 씁니다. 그래도 판단이 애매하면 "확인 필요"에서 묻습니다.

9결정한 것

모든 결정이 끝났습니다. 이 내용대로 만듭니다.

결정 완료
  • 양식 모양: 표 형태(여러 줄 입력)
  • 회신 방식: 엑셀 파일을 메일로
  • 사용 환경: 인터넷 연결됨
  • 추가 기능: 양식 저장·재사용, 중복 제출 정리
  • 양식과 취합본: 같은 틀로 통일하고, 이전 취합본에 이어서 합치기 지원
  • 기능 구성: 양식생성, 양식취합 두 가지
  • 자동 정리 범위: 확실한 것만 자동, 애매하면 묻기
  • 미제출자 확인: 넣지 않음
  • 한 파일은 한 응답으로 취급 (대리 제출 없음)
  • 기존 엑셀 양식 가져오기: 나중에 (취합 기능을 먼저 다듬은 뒤)
  • 제출자 구별: 하지 않음 (필요하면 양식에 칸을 직접 추가)
  • 최신 판단: 파일 이름의 개정번호, 없으면 파일 안 저장 시각
  • 오류 있는 줄: 합치고 노란색 표시
  • 응답자 프로그램: MS 엑셀 기준
  • 숨긴 줄·취소선: 넣고 표시
  • 읽는 범위: 인쇄영역 안만 데이터, 밖은 메모로 보관
  • 겹침 금지·허용 범위: 양식생성에서 칸마다 설정
  • 계산 관계: 양식에 따라 선택해서 설정
  • 인쇄영역 밖으로 이어진 표: 묻지 않고 바로 넣기
  • 규모: 한 번에 파일 20개 정도, 줄 수는 양식생성에서 입력 줄 수로 정함
  • 요약·집계: 넣지 않음 (취합 후 이어서 하는 일 없음)
  • 받는 파일 형식: .xlsx만

10만드는 순서

단계마다 직접 써 보시고 의견을 주시면 다음 단계로 넘어갑니다.

  1. 공통 기반 + 기능 1 양식생성
    칸 정하기(종류·꼭 입력·허용 범위·겹침 금지), 입력 줄 수, 미리보기, 빈 양식 내려받기(잠금·드롭다운·인쇄영역)
  2. 기능 2 양식취합: 사람처럼 합치기
    인쇄영역 기준 읽기, 칸 맞추기, 숨긴 줄·취소선·합친 셀 처리, 값 정리, 규칙 검사(범위·겹침 포함), 빈 회신 표시, 원본 줄 번호, 검산, 취합본 내려받기
  3. 판단 돕기 + 업무 이어가기
    확인 필요 화면, 판단 기록 시트, 개정본 정리·비교, 이어 붙이기·지난 대비 변화, 메모 시트, "〃"·여러 값·여러 시트 처리, 계산 관계, 수정 요청 문구, 양식 저장·불러오기
  4. 다음 단계: 기존 양식을 배포용 양식으로 (양식생성 고도화)
    지금 쓰고 계신 엑셀 양식을 올리면 칸을 읽어서 배포용 양식으로 바꿔 주는 기능입니다. 실제 회신 샘플로 전체를 시험한 뒤 만듭니다.
