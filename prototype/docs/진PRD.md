# PRD: 엑셀 양식 취합 웹페이지 (확정판 2)

## 1. 배경 / 문제
여러 사람에게 엑셀 양식을 메일로 보내고, 회신 파일을 받아 손으로 복사·붙여넣기로 취합하고 있다.
- 사람마다 컬럼을 바꾸거나 형식을 틀리게 입력함
- 취합 작업이 반복적이고 실수가 잦음
- 같은 파일을 고쳐서 다시 보내면 어느 게 최신인지 헷갈림

## 2. 목표
- **양식과 취합본은 같은 틀**: 제목·칸 순서·칸 이름·서식·유효성 검사가 동일, 취합본은 줄이 늘어나고 오른쪽 끝에 자동 칸만 추가 → 취합 후 재정리 없이 업무를 이어감
- 양식 정의 → 템플릿 배포 → 회신 파일 일괄 취합을 **한 페이지에서** 처리
- 잘못된 입력은 **템플릿 단계에서 막고**, 그래도 들어온 오류는 **취합 단계에서 보여줌**
- 설치·서버·로그인 없이 동작
- **사람처럼 꼼꼼하게 취합** — 양식에서 조금 벗어난 파일도 사람만큼 다룸
  1. 한 줄도 잃어버리지 않는다 (검산)
  2. 고치되, 원래 값은 남긴다 (확실한 것만 자동 정리 + 셀 메모)
  3. 애매하면 사람에게 묻는다 ("확인 필요")

### 비목표 (v1 제외)
- 웹 폼 입력, 서버/DB, 로그인
- 메일 자동 발송 (발송은 기존 메일로)
- 미제출자 확인 (불필요로 결정)
- 제출자 구별 — 취합할 때마다 대상이 달라 고정 제출자 칸을 두지 않음. 필요하면 관리자가 `부서`·`업체명` 같은 컬럼을 양식에 직접 추가
- 대리 제출 — 파일 하나 = 응답 하나
- 기존 엑셀 양식 가져오기 — 취합 기능을 다듬은 뒤 다음 단계(M4)에서
- `.xls`·`.csv` 읽기 — `.xlsx`만 받고 다른 형식은 재저장 안내
- 튀는 값 알림, 단위 착각 감지, 화면에서 바로 고치기 — 써 보고 필요하면 추가
- 요약·집계 시트, 정렬 — 취합본으로 이어서 하는 작업이 없음
- 실제 회신 샘플에 맞춘 처리 — 지금은 일반 규칙으로 정의, 샘플은 추후 시험 자료로 사용
- 서식형(고정 셀) 양식 — 목록형 표만 지원

## 3. 사용자
| 역할 | 설명 |
|---|---|
| 관리자 (취합자) | 양식을 만들고, 템플릿을 배포하고, 회신 파일을 취합 |
| 응답자 | 받은 엑셀에 값을 입력해 회신. 웹페이지를 쓰지 않음 |

## 4. 사용자 흐름
```
[기능 1. 양식생성]  ① 칸 정하기 → ② 빈 양식.xlsx 내려받기
        ↓ (메일 발송) → 응답자 입력·회신
[기능 2. 양식취합]  ③ 회신 파일 넣기 → ④ 검사·중복 정리 → ⑤ 취합본.xlsx 내려받기
        ↺ 늦은 회신: 취합본 + 새 파일 다시 넣기 / 다음 차수: 취합본으로 양식 복원
```

## 5. 기능 구성

웹페이지는 **두 개의 큰 기능(탭)** 으로 나뉜다. 경계는 "메일 발송" 시점이다.

| | 기능 1. 양식생성 | 기능 2. 양식취합 |
|---|---|---|
| 언제 | 발송 전 | 회신 후 |
| 입력 | 관리자의 칸 정의 (또는 저장된 양식·취합본) | 회신 파일들 (+ 이전 취합본) |
| 출력 | 빈 양식 파일 (`.xlsx`) | 취합본 파일 (`.xlsx`) |

### 판단: 두 기능 구성이 적절한가 → 적절함
- 업무가 실제로 "보내기 전 / 받은 뒤" 두 덩어리로 나뉘고, 사이에 사람(응답자)이 끼어 시간이 벌어진다. 화면도 그 경계에서 나누는 게 자연스럽다.
- 앞서 정한 모든 기능이 두 기능 중 하나에 깔끔하게 들어간다 (아래 표). 세 번째 기능(관리·설정 등)이 필요 없다.
- **조건 1 — 두 기능은 파일로만 연결**: 양식취합은 양식생성 화면 상태에 의존하지 않는다. 회신 파일 안 `_meta`로 양식을 스스로 알아낸다. → 다른 PC·다른 날에도 회신 파일만 있으면 취합 가능.
- **조건 2 — "같은 틀" 규칙은 공통 기반으로 한 번만 정의**: 빈 양식과 취합본을 각각 따로 만들면 모양이 어긋난다. 시트 레이아웃·서식·유효성 검사를 만드는 부분을 공유해서 두 출력물이 항상 같게 한다.

### 공통 기반 (두 기능이 함께 쓰는 것)
- **양식 정의**: 양식 ID, 이름, 버전, 컬럼 목록(이름·타입·필수·선택목록)
- **`_meta` 숨김 시트**: 양식 정의를 엑셀 안에 저장. 빈 양식·회신 파일·취합본 모두 포함
- **같은 틀 규칙**: 시트 이름 = 양식 이름, 1행 제목, 2행 정보칸(빈 양식: 안내문 / 취합본: 취합 정보), 3행 헤더, 4행부터 데이터, 열 너비·색·유효성 검사 동일

### 기능 1. 양식생성

#### 1-1. 칸 정하기
- 양식 이름 입력
- 컬럼 추가/삭제/순서 변경
- 컬럼 속성: 이름, 타입(텍스트 / 숫자 / 날짜 / 선택목록), 필수 여부, 선택목록 항목
  - **허용 범위**: 숫자·날짜의 최소 ~ 최대 (날짜는 "오늘 이후" 같은 상대값 허용)
  - **겹침 금지**: 전체 취합본에서 값이 하나뿐이어야 하는 칸 (자산번호, 사번 등)
  - **계산 관계** (선택): `금액 = 수량 × 단가`, `시작일 ≤ 종료일` 같은 칸 간 규칙. 필요한 양식에서만 추가
- **입력 줄 수**: 응답자 1인당 예상 줄 수 (예: 20). 템플릿의 입력 줄·유효성 검사·인쇄영역 크기를 정함
- 컬럼 구조를 바꾸면 버전 +1

#### 1-2. 엑셀 미리보기
- 칸을 고치면 즉시 반영
- **빈 양식 / 취합본** 전환 보기 (취합본 모양을 미리 확인)

#### 1-3. 빈 양식 파일 내려받기
- 예시 줄(선택): 첫 입력 줄에 회색 예시를 넣을 수 있음. 지우지 않고 회신돼도 취합 때 자동으로 뺌
- 같은 틀 규칙 + 2행 **안내문**(관리자 입력, 예: "11월 5일까지 회신")
- 헤더 행 잠금(시트 보호, 입력 영역만 편집 가능)
- **인쇄영역** = 1행 제목 ~ 입력 줄 끝. 인쇄영역 밖은 응답자 자유 메모 공간
- 타입별 데이터 유효성 검사: 숫자/날짜 제한, 선택목록은 드롭다운
- 필수 컬럼은 헤더에 표시(`*`, 색상)
- 파일명: `{양식이름}_v{버전}.xlsx`

#### 1-4. 양식 저장·불러오기
- 브라우저(localStorage)에 저장, 목록에서 불러오기·복제·삭제
- 파일에서 불러오기: **빈 양식 또는 취합본**을 올리면 `_meta`로 복원 → 다른 PC·다음 차수 재사용

### 기능 2. 양식취합

처리 순서 (파일마다): 열기 → 양식 알아보기 → 표 위치 찾기 → 칸 맞추기 → 줄 고르기 → 값 정리 → 규칙 검사 → 확인 필요 → 중복 정리 → 검산 → 취합본

#### 2-1. 파일 넣기
- 여러 파일을 드래그&드롭 / 파일 선택, 이전 취합본도 함께
- **`.xlsx`만** 처리. 다른 형식·암호 걸린 파일·깨진 파일은 사유 표시 후 건너뜀 ("다시 저장해서 보내 주세요")

#### 2-2. 알아보고 정리하기
- **양식 알아보기**: `_meta`의 양식 ID·버전 확인. `_meta`가 없으면 **헤더 이름 일치율**로 판단 (새 파일에 복사해 보낸 경우). 여러 양식이 섞이면 가장 많은 양식을 기본 선택
- **읽는 범위 정하기 (인쇄영역 기준)**
  - 인쇄영역이 있으면 그 안만 데이터로 읽음. 밖에 적힌 내용은 `메모` 시트로 옮김 (파일·시트·셀 위치와 함께)
  - 인쇄영역 마지막 줄까지 차 있고 표가 바로 아래로 이어지면 → **묻지 않고 바로 넣음** (빈 줄이 나오면 거기서 멈춤, 파일목록에 "인쇄영역 밖으로 이어진 n줄 포함" 기록)
  - 인쇄영역이 없으면 헤더 행 탐색으로 표를 찾음. 시트 이름이 바뀌어도 데이터 시트를 찾음
  - 같은 틀의 시트가 여러 개면 모두 읽고 출처에 시트 이름 기록 → 확인 필요
- **칸 맞추기**: 순서가 아닌 **칸 이름**으로 매칭. 공백·대소문자 무시는 자동, 그 외 비슷한 이름(예: "수 량")은 확인 필요. 양식에 없는 칸은 버리지 않고 `추가 칸` 시트에 보관. 없는 칸은 빈칸 + 기록
- **모양 속 숨은 뜻**
  - 숨긴 줄·필터로 가린 줄 → **넣고** 상태 칸에 `숨긴 줄` 표시, 취합본에서 흐리게
  - 취소선 → **넣고** 상태 칸에 `취소선` 표시, 취소선 서식 유지
  - 합친 셀 → 병합 범위의 모든 줄에 같은 값 채움 (자동)
  - `〃`, `상동`, `위와 같음` → 윗줄 값으로 채움 (자동, 원래 값은 메모)
  - 한 칸에 쉼표로 여러 값 (선택목록 칸) → 확인 필요 "나눌까요?"
  - 셀 메모(코멘트) → 취합본 같은 칸에 그대로 옮김
  - 수식 칸 → 결과 값 사용, 깨진 수식(`#REF!` 등)은 오류
- **줄 고르기**: 빈 줄, **예시 줄**(양식의 예시와 동일), **합계 줄**("합계/소계/계"), **메모 줄**(첫 칸에만 글이 있는 줄) 제외. 뺀 줄은 사유와 함께 `파일목록` 시트에 기록
- **값 정리** (결정 A: 확실한 것만 자동, 애매하면 묻기)

  | 들어온 값 | 정리 | 처리 |
  |---|---|---|
  | `1,000개`, `₩5,000` | 1000, 5000 | 자동 (쉼표·단위·화폐 기호 제거) |
  | `2026.11.1`, `11/1`, 엑셀 날짜 숫자 | 2026-11-01 | 자동 (연도 없으면 취합 연도) |
  | 앞뒤 공백·줄바꿈 | 제거 | 자동 |
  | 목록 값의 공백·대소문자 차이 | 목록 값으로 | 자동 |
  | `약 10`, `10~20` | — | 확인 필요 |
  | 목록에 없는 비슷한 값 (`notebook`) | 후보 제안 | 확인 필요 |
  | `#N/A`, `#REF!` 등 | 빈칸 | 오류 |
  - 자동으로 고친 칸은 원래 값을 **셀 메모**로 남기고 연한 파란색 표시
- **규칙 검사**: 필수값 누락, 타입 불일치, 목록 외 값, **허용 범위 밖**, **계산 관계 불일치** → 노란색 + `오류` 시트 (결정 3에 따라 취합은 함)
  - **겹침 금지**: 전체(이전 취합본 포함) 기준으로 같은 값이 있으면 해당 줄 모두 오류
  - **같은 줄 두 번**: 한 파일 안에서 모든 칸이 같은 줄 → 확인 필요
- **확인 필요**: 애매한 판단(칸 이름, 값, 개정본 여부, 추가 칸 처리)을 한 화면에 모아 예/아니오. 모두 답해야 내려받기 가능. "같은 경우 다시 묻지 않기"는 양식별로 기억

#### 2-3. 개정본 정리·이어 붙이기·검산
- 파일 하나 = 응답 하나. 제출자는 구별하지 않음 (결정 1)
- 입력 줄이 하나도 없는 파일 → `제출 · 해당 없음`으로 파일목록에 따로 표시
- **개정본 묶기**: 파일명에서 개정 표시를 떼어낸 이름이 같으면 같은 파일의 개정본으로 묶음
  - 개정 표시: `v2`, `ver2`, `rev3`, `r3`, `_2차`, `수정`, `수정본`, `최종` (구분자 `_`, `-`, 공백, 괄호 허용)
  - `파일 (2).xlsx`의 `(2)`는 개정으로 보지 않음: 같은 이름 첨부를 저장할 때 브라우저가 붙이는 표시라, 다른 사람 파일이 개정본으로 묶여 빠질 위험이 있음
- **최신 판단** (결정 2)
  1. 파일명 개정번호가 큰 것. 번호 없는 표시는 `최종 > 수정 > 표시 없음`
  2. 개정 표시가 없거나 같으면 **파일 내부 마지막 저장 시각**(xlsx 문서 속성 `modified`) — 메일 저장으로 바뀌지 않음
  3. 그래도 같거나 없으면 확인 필요
  - 참고: 문서 속성 `created`(생성일자)는 템플릿 생성 시각이 복사되어 모든 회신이 같으므로 쓰지 않음
- 화면에서 묶음별 반영 파일을 바꿀 수 있음. 묶음이 애매한 경우(예: `개발팀_비품신청_수정`)는 확인 필요
- 내용이 완전히 같은 파일 → 묻지 않고 하나만 반영
- **개정본 비교**: 반영된 개정본을 이전 개정본과 줄 단위 비교 → 바뀐 칸은 `이전 → 지금`, 새 줄은 상태 `v1 대비 추가`, 빠진 줄은 `파일목록`에 기록
- 개정본의 줄 수가 크게 줄었으면 "교체할까요, 더할까요?" 확인
- **이어서 합치기**: 이전 취합본을 `출처 파일` 컬럼 기준으로 파일별로 분해해 개별 제출로 취급 → 개정본은 교체, 신규는 추가. 이전 취합본 대비 달라진 줄도 같은 방식으로 상태 칸에 표시
- **검산**: 파일별·전체 `읽은 줄 = 반영 + 제외(사유별)` 확인, 숫자 칸은 원본 합계와 취합본 합계(이전 개정본 제외분 별도) 확인. 안 맞으면 내려받기 전 경고

#### 2-4. 취합본 내려받기
- `{양식이름}_취합_{YYYYMMDD}.xlsx`
- 데이터 시트: 같은 틀 규칙 그대로
  - 2행: 취합일 · 파일 수 · 오류 수 · 검산 결과
  - 자동 컬럼 `출처 파일`, `원본 줄`(원본 행 번호), `상태`(숨긴 줄·취소선·오류·바뀜·추가 등)는 **양식 컬럼 오른쪽 끝** (원래 열 위치 유지)
  - 인쇄영역 = 제목 ~ 마지막 줄
  - 오류 칸 노란색, 자동 정리 칸 연한 파란색 + 원래 값 메모
  - 시트 잠금 없음 (관리자가 수정 가능)
- 추가 시트: `오류`, `파일목록`(파일별 읽은/반영/제외 줄과 사유, 해당 없음, 개정본 빠진 줄), `메모`(인쇄영역 밖 내용), `판단 기록`(확인 필요에서 내린 결정 전체), `추가 칸`(있을 때만), `_meta`(숨김)
- **수정 요청 문구**: 오류가 있는 파일별로 "몇 번째 줄 어느 칸을 어떻게" 문구 생성, [복사] 버튼 (메일 발송은 하지 않음)

## 6. 비기능 요구사항
- **데이터는 브라우저 밖으로 나가지 않음** (업로드 서버 없음)
- 단일 `index.html` + CDN 라이브러리(ExcelJS)로 동작, 더블클릭으로 실행
- 대상 브라우저: 최신 Chrome / Edge
- 규모: 1회 취합 파일 20개 내외 (여유 100개), 줄 수는 양식의 입력 줄 수로 가늠
- 성능 목표: 파일 20개 3초 이내, 파일 100개 · 총 1만 행 10초 이내
- 한국어 UI
