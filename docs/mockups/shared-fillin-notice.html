공용 파일로 받은 빈칸채우기형: 무엇이 문제인가

값은 정확히 모였어요. 다만 작성자가 남의 칸에 적은 값을 버렸다는 사실이 운영자 눈에 잘 안 보여요. 아래에서 순서대로 보여 드릴게요.

1

무슨 일이 있었나

공용 파일은 누가 쓸지 모르기 때문에 다른 지사 칸을 잠그지 못해요. 그래서 중앙지사가 실수로 동탄지사 칸에 숫자를 적을 수 있어요.

중앙지사가 보낸 파일

＋

7보일러30
8펌프40

취합 결과 (정확함)

자기 칸남의 칸에 적은 값취합에 쓴 값
✓ 프로그램은 각 칸을 그 칸 주인 지사의 파일에서만 읽어요. 그래서 99는 버리고 동탄지사가 적은 30을 썼어요. 결과는 맞아요.
2

문제 ①: 99를 버렸다는 알림이 숨어 있어요

운영자는 "중앙지사가 동탄 칸에 99를 적었다"는 걸 알아야 해요. 숫자를 잘못 옮겨 적은 것일 수도 있어서 확인이 필요하거든요. 그런데 지금 화면에서는 아무 데도 표시가 없어 그냥 넘어가기 쉬워요.

3

문제 ②: 내보내기 창에 "칸이 열려 있음"이 빠졌어요

공용 파일을 고르면 주황 경고는 잘 떠요. 그런데 아래 "파일마다 들어가는 것" 목록에는 다른 지사 칸도 열려 있다는 말이 없어요. 처음 그린 시안에는 있었는데 만들 때 빠뜨렸어요. 경고에 같은 말이 있어서 급하진 않아요.

지금
⚠ 빈칸채우기형은 공용 파일이면 다른 지사 칸이 잠기지 않아요. 다른 지사 칸에 적은 값은 취합할 때 쓰지 않고 알림으로 알려 드려요.

고친 뒤
⚠ 빈칸채우기형은 공용 파일이면 다른 지사 칸이 잠기지 않아요. 다른 지사 칸에 적은 값은 취합할 때 쓰지 않고 알림으로 알려 드려요.
파일마다 들어가는 것

  • 인쇄 영역

  • 틀 고정
  • 모든 지사 칸이 열려 있음
정리
  1. 데이터는 맞아요. 남의 칸에 적은 값은 자동으로 버려져요.
  2. ①은 고치는 게 좋아요. 운영자가 "누가 남의 칸에 적었는지" 바로 알아야 확인 연락을 할 수 있어요. 공용 파일에서는 이런 실수가 자주 날 수 있어요.
  3. ②는 문구 한 줄이에요. 경고 상자가 이미 같은 말을 해서 급하진 않아요.

지사별 파일(zip)로 보내면 남의 칸이 회색으로 잠겨 있어서 이런 일이 거의 없어요. 그래서 내보내기 창에서도 지사별 파일을 추천으로 두고 있어요.
