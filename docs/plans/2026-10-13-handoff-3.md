## 4. 자유 제작형 요약 (PRD 01 3.2절, 02 2.7절, 목업 `docs/mockups/generator-free.html`)
- 오른쪽 미리보기가 **그리는 판**이 된다(`src/generator/free/FreeCanvas.tsx`).
  - 끌어서 칸 고르기, 글자 쓰기(두 번 누르기·바로 타자).
  - 고른 칸을 **입력 칸 / 입력 줄 영역 / 숫자 표**로 지정한다.
  - 칸 합치기, 지정 풀기, 옮기기, 행·열 늘리고 줄이기.
- 왼쪽 ③은 "고른 영역"이 된다(`FreePanel.tsx`).
- **④ 취합 방식 검사**(`src/contract/free.ts`의 `freeAggregationChecks`)
  - 방식마다 가능 / 고치면 됨 / 안 됨과 이유·고칠 곳, [고치러 가기]를 보여 준다.
  - 고칠 것이 있으면 내보내기를 막는다.
- 계약: 입력 영역은 **기존 블록으로 저장**한다(입력 칸 = fields, 줄 영역 = list, 숫자 표 = matrix). 그래서 셀 지도 모양은 그대로다. 판 A1은 엑셀 6행(제출처가 없으면 4행)에 놓인다.
- 같은 틀 시트의 조건:
  - 줄 영역은 0~1개.
  - 줄 영역의 아래와 오른쪽은 비어 있어야 한다.
  - 줄 영역이 없으면 입력 칸 값은 **지사별 펼치기 시트에 한 줄씩** 모인다. 이때 지사별 펼치기는 자동으로 필수다(`requiredAggregations`).
- 숫자 표가 여러 개일 수 있어 `AggregateFill.matrixSumsBy`를 추가했다.
