# 04. AI로 만들기

> 담당 코드: `src/ai/`(화면), `tools/ai/`(연결 서버·AI 설명서), `tools/moa.ts`(AI용 도구)
> 2026-10-21 처음 만듦. 결과를 보며 고쳐 나가는 기능이라 이 문서도 함께 바꾼다.

## 1. 하는 일

사용자가 **받고 싶은 것을 말로** 적으면, AI(`claude -p` 또는 `codex exec`)가 이 프로그램 규칙대로 양식 정의(`form.json`)를 만든다.
사람은 미리보기를 보고 [엑셀 내보내기] 또는 [빌더에서 열어 고치기]만 누른다. 구조 6종이나 설정 용어를 몰라도 된다.
AI는 우리 검사기를 통과한 양식만 넘기므로 취합이 의도대로 된다.

1차 범위는 **양식 만들기**까지다. 취합은 지금 [취합하기] 화면 그대로 쓴다(회신 내용은 AI로 보내지 않는다).

## 2. 구조

```
[AI로 만들기 화면] ──POST /api/ai/chat──▶ [연결 서버: vite 개발 서버에 붙은 플러그인]
                                         claude -p … --resume <id>  /  codex exec [resume <id>] …
                                         작업 폴더 ~/.hanan-moa/ai/<대화ID>/
                                           CLAUDE.md·AGENTS.md (tools/ai/AGENTS.md 복사)
                                           moa  (AI용 도구, node 한 파일로 묶은 tools/moa.ts)
                                           form.json (AI가 만든 양식), state.json (엔진별 대화 ID)
                 ◀── NDJSON 이벤트 ──── chat · status · text · form · error · done
```

- 연결 서버는 `npm run dev`(또는 `npm run preview`) 서버 안에서만 돈다. HTML 파일 하나(`dist/index.html`)로 열면 "AI 연결 서버가 꺼져 있어요"가 보이고 나머지 화면은 그대로 쓴다.
- 엔진은 화면에서 고른다(마지막 선택을 브라우저에 기억). 같은 대화 안에서 엔진별로 대화를 이어 간다.
- Codex 모델은 `MOA_CODEX_MODEL`(기본 `gpt-6-astra`), 작업 폴더 위치는 `MOA_AI_HOME`으로 바꿀 수 있다.

## 3. AI가 할 수 있는 것 (제한)

| 엔진 | 도구 | 쓰기 범위 |
|---|---|---|
| Claude | `Bash(./moa:*)`, Read, Write, Edit만 (`--tools`, `--allowedTools`, `--permission-mode acceptEdits`, MCP·슬래시 명령 끔) | 작업 폴더 |
| Codex | `-s workspace-write`, 사용자 설정 무시(`--ignore-user-config`) | 작업 폴더 |

`moa` 명령:
- `moa new <구조>`: 구조별 시작 양식 (`newSchema`)
- `moa check`: 계약 검사(`validateSchema`) → 내보내기 전 검사(`validateForExport`). "통과"가 나올 때까지 고친다
- `moa preview`: 빈 양식 엑셀 모양을 글로 (`layoutSheet`)
- `moa orgs [검색어]`: 한난 조직 이름 찾기 (`kdhcOrg`)

AI 설명서(`tools/ai/AGENTS.md`)에 구조 고르는 법, 양식 정의 요점, 작성처 규칙, 쉬운 말로 답하는 법을 적는다.

## 4. 화면

- 위쪽 메뉴 맨 앞 [AI로 만들기] (처음 열면 이 화면).
- 빈 대화: 안내 문장 + 예시 4개(누르면 입력칸에 들어감).
- 보내면 AI가 하는 일을 한 줄로 보여 준다("양식 검사 중", "엑셀 모양 확인 중"). [멈추기]로 멈출 수 있다.
- 양식이 오면 카드: 제목 · 구조 · 제출처 한 줄 · 검사 결과 + 빈 양식 미리보기(빌더와 같은 표) + [빌더에서 열어 고치기] [엑셀 내보내기] [양식 파일 저장].
  - 고칠 곳이 있으면 목록을 보여 주고 [엑셀 내보내기]를 막는다.
  - 내보내면 지사에 보낼 안내문을 보여 준다.
- 이어서 말하면(예: "교육비는 빼 줘") 같은 `form.json`을 고친다. [새 대화]로 처음부터.

## 5. 아직 안 한 것

- 쓰던 엑셀 파일을 올려서 만들기 (지금은 내용을 복사해 붙여 넣기)
- 빌더에서 고친 양식을 다시 AI에게 넘겨 이어 고치기 (연결 서버는 `form`을 받을 수 있게 되어 있음)
- AI가 취합 결과의 확인할 칸을 쉬운 말로 설명하기
