> 이 문서는 **두 개발자 모두**가 읽는 공통 문서입니다.
> - 개발자 1(생성 파트): `00-overview.md` + `01-contract.md` + `02-generator.md`
> - 개발자 2(취합 파트): `00-overview.md` + `01-contract.md` + `03-aggregator.md`

작성일: 2026-10-12 · 상태: 설계 확정(구현 전) · **개발자1안 + 개발자2안 병합본** (병합 결정은 10절)

## 1. 배경과 목적

본사→지사, 정부→우리 기관처럼 **상위 조직이 엑셀 양식을 내려보내고, 하위 조직이 작성해 돌려주면, 담당자가 하나로 합치는(취합)** 업무가 반복된다. 현재는 다음 문제가 있다.

- 양식을 만들 때 취합을 고려하지 않아, 지사마다 칸을 바꾸거나 형식이 달라져 손으로 복사·붙여넣기로 합친다.
- 누가 제출했고 누가 안 했는지, 어느 파일에 오류가 있는지 일일이 확인해야 한다.
- 취합 작업이 반복적이고 실수가 잦다. 한 줄이 빠져도 알아채기 어렵다.

**목표**
1. 처음부터 **"취합 가능한 형태"로 양식을 만든다.** 잘못된 입력은 양식 단계(엑셀 입력 규칙)에서 막는다.
2. 돌아온 파일을 **자동으로 검증·정리·취합한다.** 그래도 들어온 오류는 취합 단계에서 보여주고, 운영자가 수정안을 고르거나 직접 고친다.
3. **양식과 취합본은 같은 틀**: 제목·칸 순서·칸 이름·서식이 같고, 취합본은 줄이 늘어나고 오른쪽 끝에 자동 칸만 추가된다 → 취합 후 재정리 없이 업무를 이어간다.
4. **사람처럼 꼼꼼하게 취합**: 양식에서 조금 벗어난 파일(숨긴 줄, 합친 셀, `〃`, 단위 붙은 숫자 등)도 사람만큼 다룬다.
   - 한 줄도 잃어버리지 않는다 (검산)
   - 고치되, 원래 값은 남긴다 (자동 정리 + 셀 메모)
   - 애매하면 사람에게 묻는다

## 2. 사용자와 사용 장면

| 사용자 | 하는 일 |
|---|---|
| 운영자 (본사·본부 담당자) | 웹 화면에서 양식을 만들고, 엑셀 파일로 내보내 배포한다. 돌아온 파일을 넣어 취합한다. |
| 작성자 (지사·기관 담당자) | 받은 엑셀 파일을 **MS Excel 또는 한셀**로 열어 작성하고 돌려보낸다. 우리 프로그램을 쓰지 않는다. |

주요 장면:
1. **본사 → 지사 (지사 목록 있음)**: 본사 인사팀이 15개 지사에 조사표를 보내고 취합한다. 미제출 지사를 확인한다. (주력)
2. **목록 없는 수합**: 취합할 때마다 대상이 달라 고정 목록이 없다. 파일 하나 = 응답 하나로 모은다. 필요하면 `부서`·`업체명` 같은 칸을 양식에 직접 넣는다.
3. **본사 → 본부 → 지사 (다단계)**: 본부가 지사 파일을 취합하고, 본사가 본부 취합본들을 다시 취합한다.
4. **빈칸 채우기**: 본사가 대부분 채운 표를 모두에게 보내고, 각자 해당 빈칸만 채워 돌려주면 하나의 완성된 표로 겹쳐 합친다.
5. **정부 → 우리 기관**: 정부 양식을 받아 지사에 재배포한다. MVP에서는 운영자가 같은 항목을 빌더로 다시 만들어 쓴다. (정부 양식을 그대로 들여오는 기능은 로드맵의 "외부 양식 표준화")

파일 전달은 **메신저·메일·공문으로 엑셀 파일 자체를 주고받는다.** 프로그램은 파일을 만들고 읽기만 한다(메일 자동 발송 없음).

## 3. 제품 형태와 기술 원칙

- **서버 없는 브라우저 웹앱.** 모든 처리는 사용자의 브라우저 안에서 끝나며, 파일 내용이 외부로 전송되지 않는다(개인정보 보호). 로그인 없음.
- 기술 스택: **React + TypeScript + Vite**, 엑셀 처리 **ExcelJS**, 압축 **JSZip**, 테스트 **Vitest**, 스타일 **Tailwind CSS**.
- **배포 결과물은 `index.html` 한 파일**: 개발은 파트별로 나눠 하고, 빌드 시 `vite-plugin-singlefile`로 JS·CSS·라이브러리를 모두 한 파일에 넣는다. 더블클릭으로 실행되고, CDN·인터넷 연결이 필요 없다. 원하면 같은 파일을 정적 호스팅에도 올릴 수 있다.
- 개발자2가 만든 프로토타입(`index.html` + `selfcheck.js`, ExcelJS 4.4.0)은 **로직 참고본**으로 쓴다. 값 정리·엑셀 모양 해석·검산 로직과 지저분한 회신 파일 세트를 이식한다.
- 지원 브라우저: 최신 Chrome, Edge. 한국어 UI.
- 제품 안에 AI 기능은 넣지 않는다. (로드맵에서 검토)

## 4. 용어

| 용어 | 뜻 |
|---|---|
| 양식 | 운영자가 정의한 조사표. 한 양식은 **입력 시트 1개**로 구성된다. |
| 양식 정의 (`FormSchema`) | 양식의 설계도. 항목, 구조, 서식, 취합 방식, 지사 목록을 담은 데이터. |
| 블록 | 양식을 구성하는 단위. `fields`(항목:값), `list`(목록), `matrix`(고정 표), `grid`(빈칸채우기 표) 네 종류. |
| 양식 구조 | 블록 조합. 목록형 = list, 표형 = matrix, 혼합형 = fields + list, 빈칸채우기형 = grid. |
| 서식 | 칸마다 정하는 값의 모양. 숫자(자릿수·쉼표·단위), 날짜(표시 형식), 텍스트(글자 수), 패턴(전화번호 등). 취합 시 이 서식대로 값을 정리한다. |
| 메타 (`FileMeta`) | 생성된 엑셀 파일 안에 숨겨 넣는 설계도 사본 + 셀 위치 정보 + 지사명. |
| `_meta` 시트 | 메타가 저장되는 숨김 시트(veryHidden). 작성자에게 보이지 않는다. |
| 셀 지도 (`CellMap`) | 각 항목의 값이 엑셀의 어느 칸에 있는지 적은 표. |
| 인쇄영역 | 양식 시트의 제목 ~ 입력 영역 끝. **안 = 데이터, 밖 = 작성자 자유 메모.** |
| 제출본 | 작성자가 작성해 돌려준 엑셀 파일. 메타의 `kind = 'submission'`. |
| 취합본 | 취합 결과 엑셀 파일. 메타의 `kind = 'aggregate'`. 다시 취합의 입력이 될 수 있다. |
| 같은 틀 시트 | 취합본의 첫 시트. 빈 양식과 같은 모양에 모든 제출 값을 담는다(5.1). |
| 자동 수정안 | 취합 파트가 오류 칸에 제안하는 고친 값(예: `"1,000개"` → `1000`). |
| 지사/기관 목록 | 배포 대상 조직 목록. **선택 사항.** 있으면 지사별 파일·제출 현황, 없으면 파일 하나 = 응답 하나. |
| 공통 계약 | 생성 파트와 취합 파트가 함께 지키는 약속. `src/contract/`와 `01-contract.md`. |

## 5. MVP 범위

### 5.1 포함

**양식 만들기 (생성 파트)**
- 웹 빌더에서 양식 정의, **실시간 미리보기**(빈 양식 / 취합본 모양 전환)
- 양식 구조 4종: **목록형, 표형, 혼합형, 빈칸채우기형**
- 항목 타입 6종: 텍스트, 숫자, 날짜, 목록 선택, 메모, **패턴**(전화번호·휴대폰·이메일·사업자번호)
- **칸별 서식**: 숫자(정수/소수 자릿수, 천 단위 쉼표, 단위, 최소~최대), 날짜(표시 형식, 연도·연월 포함, 허용 범위 — "오늘 이후" 같은 상대값 허용), 텍스트(최대 글자 수)
- 목록 입력 줄 수, 예시 줄(선택), 인쇄영역
- 지사/기관 식별 3방식: 목록 있음(지사별 파일 zip) / 지사명 입력칸 / **식별 안 함**
- 엑셀 입력 규칙(데이터 유효성 검사), 시트 보호, 숨김 메타, 파일 속성 이중 기록
- 양식 JSON 저장·불러오기, 브라우저에 최근 양식 저장, 빈 양식·취합본에서 양식 복원

**취합하기 (취합 파트)**
- xlsx 여러 개 또는 zip 업로드(`.xls`·`.csv`·암호 파일은 사유 표시 후 건너뜀, "다시 저장해서 보내 주세요")
- 파일 식별(메타 → 파일 속성 → 양식 JSON/머리글 일치율 순)
- **엑셀 모양 해석**: 인쇄영역 기준 읽기, 숨긴 줄·취소선·합친 셀·`〃`, 빈 줄·예시 줄·합계 줄·메모 줄 제외, 양식에 없는 칸과 인쇄영역 밖 내용 보관
- **서식대로 값 정리**: 확실한 것은 자동 정리(원래 값은 셀 메모), 애매한 것은 자동 수정안 제시
- 검증, 검토 화면, **오류 칸별 "자동 수정안 / 직접 수정" 선택**, 파일 단위 제외
- 직접 수정한 내용이 반영된 **수정된 회신 파일 사본** 내려받기
- 취합본: **같은 틀 시트(항상)** + 선택 시트(지사별 펼치기, 시트 모으기, 제출 현황) + 오류·파일목록·메모·판단 기록 시트
- **검산 리포트**: 읽은 줄 = 반영 + 제외(사유별), 숫자 칸 원본 합계 = 취합본 합계, 양식 수식 칸 재계산 일치, 미제출·누락 파일
- 취합본 다시 취합(다단계)

**오류·예외 처리 정책 (확정)**

| 상황 | 처리 |
|---|---|
| 값 오류 (필수칸 빈칸, 숫자칸에 글자, 서식 불일치 등) | 칸마다 **자동 수정안 / 직접 수정** 선택. 고르지 않으면 **자동 수정안 적용**(수정안이 없으면 원래 값 + 노란색). 파일 전체 **제외**도 가능 |
| 서식 차이가 확실한 값 (`1,000개`, `2026.11.1`, 앞뒤 공백) | **자동 정리**, 원래 값은 셀 메모, 연한 파란색 |
| 구조 변경 (열 삭제·순서 변경·칸 이름 공백 차이) | **머리글 이름으로 맞춰서 자동 포함**, 사라진 열은 빈칸 + 경고. 비슷한 이름(예: "수 량")은 확인 |
| 다른 양식 파일 | **자동 제외**하고 알림 |
| 같은 지사 중복 제출 (지사 목록 있음) | **최신 파일 사용**(파일 내부 마지막 저장 시각), 운영자가 다른 파일로 바꿀 수 있음 |
| 중복 파일 (지사 목록 없음) | **내용이 완전히 같은 파일만** 하나로. 나머지는 별개 응답 |
| 목록 밖 지사명 / 지사를 알 수 없는 파일 | **운영자가 지사 목록에서 연결** |
| 빈칸채우기형에서 같은 칸에 서로 다른 값 | **확인 필요**: 어느 값을 쓸지 운영자가 선택 |

### 5.2 제외 (로드맵으로)
- 개정본 처리(파일명 `v2`·`수정`·`최종` 인식, 개정본 간 비교)
- 칸 간 계산 관계(`금액 = 수량 × 단가`, `시작일 ≤ 종료일`), 겹침 금지(자산번호 등 전체 중복 금지)
- 수정 요청 문구 생성
- 빈칸채우기형의 지사별 배정 영역(지사마다 편집 가능 영역 지정)
- 외부 양식 들여오기·표준화(기존 엑셀을 올려 양식으로 변환)
- 여러 시트에 걸친 양식
- 나머지 취합 방식 (8절)
- 튀는 값 알림, 원본과 나란히 보기, "같은 경우 다시 묻지 않기"
- AI 기능
- 서버, 로그인, 제출 이력 저장, 메일 자동 발송, 웹 폼 입력

## 6. 성공 기준

1. 운영자가 개발 지식 없이 10분 안에 혼합형 양식을 만들고 15개 지사용 파일을 내려받을 수 있다.
2. 미리보기와 실제 엑셀 파일의 칸 배치가 일치한다. 취합본 첫 시트가 빈 양식과 같은 틀이다.
3. 작성자가 MS Excel에서 작성·저장한 파일을 넣으면 수작업 없이 취합 파일이 나온다.
4. 오류·예외 유형이 모두 검토 화면에 표시되고, 정책대로 처리된다.
5. 지저분한 회신 파일 세트(숨긴 줄, 합친 셀, 단위 붙은 숫자, 합계 줄 등)를 넣어도 **검산이 일치**한다(한 줄도 빠지지 않음).
6. 본부 취합본 2개를 본사가 다시 취합하면, 지사 단위 결과가 직접 취합한 결과와 같다.
7. 파일 20개를 3초, 파일 100개·총 10만 행을 10초 이내에 처리한다(최신 노트북, Chrome).
8. 파일 내용이 브라우저 밖으로 전송되지 않는다(네트워크 요청 없음).

| D4 | 배포 방식 | `index.html` 한 파일 전달(기본) + 필요 시 정적 호스팅 |
| D5 | 개발자 배정 | 생성 1명(개발자1), 취합 1명(개발자2) |
| D6 | 데모 시나리오와 실제 업무 양식 샘플 | "교육 참가자 조사" 혼합형 15개 지사 + 빈칸채우기형 1종. 실제 회신 샘플은 추후 시험 자료로 사용 |

## 8. 로드맵 (MVP 이후)

**취합 방식 추가 후보** (플러그인 구조라 파일 하나씩 추가)
- 칸별 합계, 항목별 소계, 지사별 요약, 교차표(피벗), 응답 분포, 평균·최대·최소, 순위·정렬, 키 기준 중복 제거, 기준표와 대조·병합, 전기 대비 증감, 계층 집계(지사→본부→전체)

**기능 확장**
- 개정본 처리: 파일명 개정 표시 인식(`v2`, `rev3`, `_2차`, `수정`, `최종`; `파일 (2)`는 제외), 최신 판단(개정번호 → 파일 내부 저장 시각 → 확인), 개정본 간 바뀐 칸 비교
- 칸 간 계산 관계·겹침 금지 규칙
- 수정 요청 문구: 오류 파일별 "몇 번째 줄 어느 칸을 어떻게" 문구 + [복사]
- 외부 양식 표준화: 정부·외부 기관 양식을 들여와 우리 양식 정의로 변환 (빈칸채우기형 표를 기존 엑셀에서 가져오기 포함)
- 빈칸채우기형 지사별 배정 영역
- 여러 시트짜리 양식
- AI 기능 검토: 자연어로 양식 초안 만들기, 외부 양식 자동 분석, 오류 값 보정 제안
