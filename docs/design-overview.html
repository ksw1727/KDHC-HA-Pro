본사가 지사에 조사표를 보내고, 돌아온 파일을 하나로 합치는 일을 자동으로 처리합니다. 두 개발자가 각자 쓴 설계안을 하나로 합쳐, 지금까지 정한 내용을 개발 용어 없이 정리한 문서입니다.

01

한눈에 보기

지금은 이런 문제가 있습니다.

지사마다 칸이 달라짐양식을 만들 때 합칠 일을 생각하지 않아서, 지사가 열을 지우거나 순서를 바꾸면 손으로 맞춰야 합니다.
값 모양이 제각각"1,000개", "₩5,000", "2026.11.1"처럼 같은 뜻을 다르게 적어서 합친 뒤에 다시 고쳐야 합니다.
누가 냈는지, 빠진 줄은 없는지 모름미제출 지사, 잘못 쓴 칸, 복사하다 빠뜨린 줄을 일일이 확인해야 합니다.

그래서 이렇게 풉니다.

1단계양식 만들기웹 화면에서 항목과 서식(숫자·날짜·글자·전화번호 등)을 정하면 입력 규칙이 걸린 엑셀이 만들어집니다.
중간배포와 회수지금처럼 메신저·메일·공문으로 엑셀 파일을 주고받습니다. 지사는 우리 프로그램을 쓰지 않습니다.
2단계합치기(취합)돌아온 파일을 한꺼번에 넣으면 정리·검사하고, 애매한 것만 묻고, 양식과 같은 모양의 취합본을 줍니다.

사람처럼 꼼꼼하게 합치는 세 가지 원칙

1한 줄도 잃어버리지 않는다읽은 줄 = 넣은 줄 + 뺀 줄(사유별)을 매번 맞춰 봅니다. 숫자 합계도 원본과 대조합니다.
2고치되, 원래 값은 남긴다확실한 것만 자동으로 고치고, 고친 칸에는 원래 값을 메모로 붙여 둡니다.
3애매하면 사람에게 묻는다"약 10"처럼 애매한 값은 수정안을 보여 주고 운영자가 고르게 합니다.
모든 처리는 사용자 컴퓨터의 인터넷 창(브라우저) 안에서만 일어납니다. 프로그램은 index.html 파일 하나로, 더블클릭하면 열리고 인터넷 연결이 없어도 동작합니다. 파일이 외부로 나가지 않으므로 개인정보가 담긴 조사표에도 안전합니다.

07

숨은 설계도: 두 파트를 잇는 약속

만들기 담당과 합치기 담당이 따로 일하려면, "엑셀 파일 안에 무엇을 어떤 모양으로 적어 둘지"를 먼저 약속해야 합니다. 이 약속을 공통 계약이라고 부릅니다. 이번 병합에서 "같은 틀"을 그리는 부분도 공통 계약에 넣어, 빈 양식과 취합본이 항상 같은 모양이 되게 했습니다.

택배로 비유하면, 만들기 담당은 상자(엑셀)에 송장(숨은 설계도)을 붙여 보내고, 합치기 담당은 돌아온 상자의 송장만 보고 내용물을 정리합니다. 그래서 다른 PC, 다른 날에도 회신 파일만 있으면 합칠 수 있습니다.

지사가 숨은 시트를 지우면? 3단계로 막습니다

1아예 안 보이게일반 "숨기기"보다 강한 숨김을 써서 엑셀 메뉴에서 찾을 수 없고, 시트 삭제도 잠가 둡니다.
2두 군데 적어 두기양식 번호와 지사 이름은 파일 속성에도 적어 둡니다. 내용을 몰래 고치면 알아챕니다.
3그래도 사라지면새 파일에 복사해 붙여넣은 경우입니다. 다른 회신 파일이나 저장해 둔 양식과 제목 줄 이름이 70% 이상 같으면 같은 양식으로 보고 이름으로 맞춰 합칩니다.

검산: 한 줄도 빠지지 않았는지 맞춰 보기

결과 파일을 받기 전에 아래를 계산해 화면 위쪽과 "검산" 시트에 보여 줍니다. 하나라도 안 맞으면 경고합니다.

줄 수파일마다, 그리고 전체로 읽은 줄 = 넣은 줄 + 뺀 줄(빈 줄·예시·합계·메모·운영자 제외·중복 사유별).
취합 누락넣은 파일 = 반영 + 제외 + 건너뜀(사유별). 지사 목록을 쓰면 미제출 지사 목록.
숫자 합계숫자 칸마다 원본 합계 = 취합본 합계. 수정·제외로 생긴 차이는 따로 표시("수정으로 +5, 제외로 -120").
수식 검산표형 합계 칸, 지사가 직접 적은 합계 줄이 실제 합과 맞는지. 안 맞으면 해당 파일에 표시.

두 사람이 나눠서 만드는 방법

각자 AI(LLM)에게 일을 맡길 때, 공통 문서 2개 + 자기 담당 문서 1개만 주면 상대 작업을 몰라도 개발할 수 있게 문서를 나눴습니다.

공통00 개요 · 01 공통 계약목적, 범위, 용어, 숨은 설계도의 정확한 모양, 서식 규칙, 같은 틀 그리기.
개발자 102 만들기 파트양식 만들기 화면, 서식 편집, 빈칸채우기 표 편집, 미리보기, 엑셀 생성.
개발자 203 합치기 파트파일 읽기, 모양 해석, 값 정리, 확인할 칸, 합치기, 검산, 결과 파일.
합치기 담당은 만들기 파트가 끝나길 기다리지 않습니다. 첫날 함께 만든 연습용 샘플 파일(정상 파일, 오류 파일, 숨은 시트가 지워진 파일, 개발자2 시제품의 지저분한 회신 파일 세트 등)로 바로 시작합니다.

공통 계약은 혼자 바꾸지 않습니다. 바꿀 일이 생기면 상대에게 알리고 함께 고칩니다. 이 규칙은 각자의 AI에게도 알려 줍니다.

결정해 주셔야 할 것

아래 항목은 기본안을 정해 두었습니다. 바꾸실 것만 알려 주세요.

  1. 한셀에서 저장해도 숨은 설계도·인쇄영역이 남는지
    공공기관은 한셀을 많이 씁니다. 0단계에서 직접 시험한 뒤 결과를 보고 대응을 정합니다. 시험 후 결정
  2. 잠금에 비밀번호를 걸지
    걸지 않으면 엑셀을 조금 아는 사람은 잠금을 풀 수 있습니다. 기본안: 프로그램이 정한 비밀번호 사용
  3. 목록형 양식의 기본 줄 수
    지사가 줄을 끼워 넣을 수 없으므로 미리 만들어 둘 줄 수입니다. 양식마다 바꿀 수 있습니다. 기본안: 100줄
  4. 프로그램을 어떻게 나눠 줄지
    기본은 index.html 파일 하나를 전달해 더블클릭으로 열기. 원하면 같은 파일을 인터넷 주소로도 올릴 수 있습니다. 기본안: 파일 전달
  5. 누가 어느 파트를 맡을지
    만들기 담당 개발자 1, 합치기 담당 개발자 2.
  6. 시연 시나리오와 실제 업무 양식 샘플
    실제로 쓰는 양식과 회신 파일(개인정보는 지운 것)을 주시면 시험과 시연이 훨씬 현실적이 됩니다.

나중에 할 것 (이번 범위 밖)

개정본 처리파일명의 v2·수정·최종을 알아보고 최신본을 골라, 이전 판과 바뀐 칸을 비교. ("파일 (2)"는 개정으로 보지 않음)
칸 사이 규칙금액 = 수량 × 단가, 시작일 ≤ 종료일 검사. 자산번호처럼 전체에서 겹치면 안 되는 값 검사.
수정 요청 문구오류 파일마다 "몇 번째 줄 어느 칸을 어떻게" 고쳐 달라는 문구를 만들어 복사.
외부 양식 표준화정부·외부 기관 양식이나 기존 엑셀을 들여와 우리 양식으로 바꾸기. 지금은 간단한 양식만 직접 만듭니다.
빈칸채우기형 영역 배정지사마다 고칠 수 있는 칸을 따로 정해 주기.
합치는 방법 추가칸별 합계, 항목별 소계, 지사별 요약, 피벗 표, 응답 분포, 평균·최대·최소, 순위, 기준표 대조, 지난 차수 대비 증감, 본부 단계별 합계.
여러 시트짜리 양식한 양식이 시트 2장 이상으로 나뉜 경우.
AI 기능 검토말로 설명하면 양식 초안 만들기, 외부 양식 자동 분석, 잘못된 값 고치기 제안.

용어 풀이

브라우저 웹앱
크롬·엣지 같은 인터넷 창에서 열어 쓰는 프로그램. 설치가 필요 없습니다.
서버 없음
파일을 다른 컴퓨터로 보내지 않고, 내 컴퓨터 안에서만 처리한다는 뜻입니다.
취합
여러 지사가 낸 파일을 하나로 합치는 일.
같은 틀
빈 양식과 취합본이 같은 모양이라는 약속. 취합본은 줄이 늘고 오른쪽 끝에 자동 칸만 붙습니다.
서식
칸에 들어갈 값의 모양. 숫자 자릿수·단위, 날짜 표시 방법, 글자 수, 전화번호 모양 등.
빈칸채우기형
본사가 대부분 채운 표를 모두에게 보내고, 각자 해당 빈칸만 채워 돌려주면 한 장으로 겹쳐 완성하는 양식.
인쇄영역
엑셀에서 인쇄할 범위. 이 프로그램은 인쇄영역 안을 자료, 밖을 메모로 봅니다.
수정안
잘못 들어온 값에 대해 프로그램이 제안하는 고친 값. 운영자가 받아들이거나 직접 고칩니다.
검산
읽은 줄 수와 넣은 줄 수, 원본 합계와 취합본 합계가 맞는지 확인하는 일.
공통 계약
두 개발자가 지키기로 한 약속. "엑셀 안에 설계도를 이런 모양으로 적는다."
숨은 설계도 시트
엑셀 안에 들어 있지만 작성자에게는 보이지 않는 시트. 양식 정보와 칸 위치가 적혀 있습니다.
양식 파일 (JSON)
만든 양식을 저장해 두는 작은 파일. 다음에 다시 쓰거나, 숨은 시트가 사라진 파일을 살릴 때 씁니다.
입력 규칙
엑셀의 "데이터 유효성 검사". 숫자 칸에 글자를 못 쓰게 막는 기능입니다.
시트 잠금
엑셀의 "시트 보호". 정해진 칸만 고칠 수 있게 하는 기능입니다.
