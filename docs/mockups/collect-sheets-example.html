시트 모으기형: 지사·부서가 자유롭게 쓴 시트를 한 파일에 모으기

칸 규칙이 없는 보고서처럼, 지사·부서마다 모양이 달라도 시트 그대로 한 파일에 모으는 양식입니다. 양식 만들기 단계에서 "시트 모으기형"을 고르면, 프로그램은 누가 낸 파일인지만 확실히 알 수 있게 만들고, 시트 내용은 지사가 마음대로 쓰게 둡니다. 예시: 본사가 15개 지사에서 "10월 안전점검 결과 보고서"를 받는 상황입니다.

10.22부터 양식 만들기는 따로 탭 없이 [AI로 만들기] 화면 오른쪽 패널로 열려요. 아래 화면도 그 배치로 고쳤습니다(왼쪽 = AI 대화, 오른쪽 = 양식 만들기 패널).

규칙 정리

상황처리
지사마다 시트 모양이 다름그대로 복사. 칸 검사 없음
지사가 파일 이름을 바꿈숨김 시트의 지사명으로 알아봄
지사가 시트를 더 만듦기본은 "보고서 시트만"(확정). 양식 만들 때 "모든 시트"를 고르면 대구_사진처럼 지사명을 붙여 모두 모음
한난MOA로 만들지 않은 파일 / 숨김 정보가 사라진 파일자동 제외 (확정)
같은 지사가 두 번 냄다른 구조와 같음: 최신 파일 사용, 운영자가 바꿀 수 있음
시트 이름 길이·특수문자엑셀 제한(31자, / \ ? * [ ] 금지)에 맞게 자동으로 줄이고 바꿈
그림·차트·도형이번 버전에서는 옮기지 않음(향후 추가 기능). 그림이 있던 시트는 "그림 n개는 옮겨지지 않았어요"로 기록
제출처가 지사가 아니라 부서양식 만들 때 제출처를 부르는 말을 "부서"로 고르면 "부서명", "부서별 시트"로 바뀜
바뀌는 곳 (개발자 2와 합의 필요)
위치변경

취합 파트 03-aggregator.md칸 검사를 건너뛰고 시트 복사, 목차 시트(바로가기 링크) 만들기, 한난MOA 양식이 아닌 파일 자동 제외
