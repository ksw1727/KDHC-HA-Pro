대화가 주인공, 오른쪽은 설정 패널만

대화창이 화면의 약 80%를 쓰고, 오른쪽 패널에는 양식 만들기 첫 화면(구조 카드) 없이 ① 기본 정보 ~ ⑤ 제출처 설정만 둡니다. 따로 있던 빌더 미리보기는 없애고, 대화 속 양식 카드의 미리보기가 패널에서 고치는 즉시 바뀝니다. 아래 화면은 실제로 눌러 볼 수 있어요.

1대화창 = 메인 (약 80%)말하고, 결과를 보고, 다시 말하는 곳. 미리보기도 여기 카드 안에 있어요.
2오른쪽 = 설정 패널 (약 20%)첫 화면·큰 미리보기 없이 ①~⑤ 설정만. 스위치로 켜고 끄고, 경계를 끌어 너비 조절.
3고치면 카드가 바로 바뀜패널에서 바꾼 칸은 노랗게 반짝이고, 카드 아래에 "패널에서 고친 내용"이 쌓여요. 다음에 말하면 AI도 고친 양식에서 이어 가요.

혼합형으로 만들었어요. 위에 담당자·연락처를 한 번 받고, 아래에 참가자 명단(이름·직급·참가 희망일·교육비)을 여러 줄 받아요. 오른쪽 패널에서 고치면 아래 미리보기에 바로 반영돼요.
    고칠 내용을 말해 주세요 (예: 교육비는 빼 주세요)
    v1 · 자동 저장됨
    1 2 3
    이렇게 눌러 보세요
    1. 오른쪽 ① 기본 정보에서 제목을 바꿔 보세요 → 카드 미리보기 1행이 바로 바뀌고 반짝여요.
    2. ③ 항목·서식에서 직급을 누르고 필수를 켜거나 이름을 바꿔 보세요. 미리보기의 머리글을 눌러도 그 항목이 패널에서 열려요.
    3. ⑤ 제출처에서 부르는 말을 부서로 바꾸거나 목록을 지워 보세요 → "지사명"이 "부서명"으로, 검사 결과가 "고칠 곳"으로 바뀌어요.
    4. 위쪽 양식 설정 패널 스위치를 끄면 대화가 화면 전체를 써요.
    지금 화면에서 바뀌는 점
    • 대화 : 패널 = 약 8 : 2 (이전엔 4 : 6). 패널은 300px 밑으로 줄지 않아요.
    • 패널에서 양식 만들기 첫 화면(구조 카드·최근 양식)을 뺌. 구조는 ② 양식 구조에서 고르고, 새 양식은 대화로 시작해요.
    • 패널 안 큰 미리보기를 뺌. 미리보기는 대화 속 마지막 양식 카드 하나로 통일.
    • 카드와 패널은 같은 양식을 봐요(지금의 "빌더에서 고침" 연동을 저장할 때가 아니라 고칠 때마다).
    • 열려 있는 양식이 없으면 패널에 "대화로 양식을 만들거나 양식 파일을 여세요" 안내만 보여 줘요. (이 목업에는 없음)
