PRD 보완 검토

사람처럼 꼼꼼하게 취합하려면

사람은 취합하면서 눈으로 보고 알아서 맞추는 일을 많이 합니다. 지금 기획은 "양식대로 잘 낸 파일"은 잘 합치지만, 양식에서 조금 벗어난 파일은 사람만큼 다루지 못합니다. 무엇을 더해야 하는지 정리했습니다.

1사람처럼 취합하기 위한 세 가지 원칙

🧮

한 줄도 잃어버리지 않는다

사람은 "다 옮겼나?" 하고 세어 봅니다. 웹페이지도 읽은 줄 수 = 반영한 줄 + 뺀 줄인지 매번 검산하고, 뺀 줄은 이유와 함께 남깁니다.

✍️

고치되, 원래 값은 남긴다

"1,000개"를 1000으로 바꾸는 건 사람도 하는 일입니다. 다만 원래 무엇이 적혀 있었는지 셀 메모로 남기고, 고친 칸은 색으로 표시합니다.

🙋

애매하면 사람에게 묻는다

"수 량"이 "수량"인지, "김민수"와 "김 민수"가 같은 사람인지 같은 것은 짐작해서 정하지 않습니다. 한곳에 모아서 예/아니오로 묻습니다.

2사람이 하는 일 vs 지금 기획

사람이 취합할 때 거치는 단계별로, 지금 기획이 어디까지 해 주는지 표시했습니다. 막대가 길수록 사람 손이 덜 갑니다.

지금 기획으로 됨빈틈: 결국 사람이 다시 손봐야 함
① 파일 열기받은 첨부를 엽니다
.xlsx 열기옛날 .xls · 암호 · 깨진 파일
② 양식 맞는지 보기우리가 보낸 양식인가
숨김 양식정보 확인새 파일에 복사해서 보낸 경우
③ 표 찾고 칸 맞추기칸이 바뀌어도 눈으로 맞춤
정위치만칸 순서 바뀜 · 이름 살짝 다름 · 칸 추가
④ 옮길 줄 고르기쓸데없는 줄은 뺌
빈 줄 빼기예시 줄 · 합계 줄 · "이상입니다" 메모
⑤ 값 알아듣기뜻을 보고 정리
틀리면 표시"1,000개" · "11.1" · 공백 정리
⑥ 같은 사람 정리누가 냈는지 판단
이름 같으면 최신만표기 차이 · 대리 제출 · 같은 파일 두 번
⑦ 훑어보고 검산빠진 것 없나, 이상한 값 없나
오류 목록줄 수 검산 · 튀는 값 · 고친 칸 표시
⑧ 후속 조치안 낸 사람, 틀린 사람에게 연락
오류 목록미제출자 확인 · 수정 요청 문구

막대 길이는 정확한 수치가 아니라, 사람이 손봐야 하는 정도를 대략 나타낸 것입니다.

3보완된 처리 순서

회신 파일 하나가 웹페이지 안에서 거치는 단계입니다. 초록색은 새로 추가하는 단계, 파란 테두리는 기존 단계를 보강하는 것, 회색은 지금 기획 그대로입니다.

C. 같은 사람 판단: 사람 눈으로 하던 판단

이름 표기 차이

공백과 괄호는 무시하고 같은 사람으로 보되, 화면에서 "같은 사람인가요?"라고 한 번 묻습니다.

완전히 같은 파일

같은 파일을 실수로 두 번 넣음

내용이 한 글자도 다르지 않으면 묻지 않고 하나만 반영합니다.

대리 제출

팀장이 팀원 여러 명 몫을 한 파일로 보냄

줄마다 이름을 적을 수 있는 "대상자" 칸을 양식에 둘지 정해야 합니다. 아래 7번 "결정할 것"을 보세요.

일부만 다시 보냄

수정본에 바뀐 줄만 담아 보냄

기본은 "전체 교체"입니다. 줄 수가 크게 줄었으면 "교체할까요, 더할까요?"라고 묻습니다.

D. 검산과 기록: "다 옮겼나?"를 대신 확인

  • 숫자 칸은 원본 합계 = 취합본 합계도 함께 확인합니다. 중복으로 빠진 몫은 따로 표시합니다.
  • 취합본의 "파일목록" 시트에 파일별로 읽은 줄, 반영한 줄, 뺀 줄과 이유를 남깁니다.
  • 다른 사람들과 크게 다른 값(예: 다들 1~3인데 혼자 300)은 오류가 아니라 확인 권장으로 표시합니다.

E. 후속 조치: 취합 다음에 사람이 하던 일

미제출자 확인

대상자 명단(이름만)을 한 번 붙여 넣어 두면, 취합할 때마다 안 낸 사람 목록이 나옵니다.

지난 기획에서는 "하지 않는 것"이었지만, 사람이 취합할 때 가장 많이 하는 일이라 다시 검토를 권합니다. 서버 없이도 됩니다.

수정 요청 문구

이지은님, 제출하신 「2026 비품 신청」에서 아래 내용을 확인 부탁드립니다.
- 6번째 줄 수량: "약 10개" (숫자로 입력)
- 8번째 줄 품목: 비어 있음

사람마다 문구를 만들어 주고 [복사] 버튼만 둡니다. 메일 발송은 하지 않습니다.

6우선순위: 무엇부터 더할까

오른쪽 위로 갈수록 효과는 크고 만들기는 쉬운 것입니다.

1단계 · 꼭 넣기
  1. 검산 (한 줄도 안 잃기)
  2. 칸 이름으로 맞추기
  3. 값 정리 (확실한 것만)
  4. 예시·합계·메모 줄 빼기
  5. 고친 칸 표시 + 원래 값 메모

이게 없으면 결국 사람이 취합본을 다시 훑어야 합니다.

2단계 · 권장
  1. 확인 필요 화면
  2. 표 위치 자동 찾기
  3. 이름 표기 차이 묻기
  4. 미제출자 확인
  5. 수정 요청 문구

사람 판단이 필요한 일을 한곳에 모아 줍니다.

3단계 · 필요할 때
  1. .xls·.csv 열기
  2. 튀는 값 알림
  3. 대리 제출
  4. 화면에서 바로 고치기

실제로 써 보고 자주 생기면 추가합니다.

7결정해 주셔야 할 것

결정 A

자동으로 고치는 범위는 어디까지?

확실한 것만 자동, 애매하면 묻기 (추천)쉼표·단위·공백·날짜 모양은 자동으로 고치고, "약 10"이나 비슷한 이름은 묻습니다.
하나도 고치지 않고 표시만가장 안전하지만 사람이 고칠 일이 많습니다.
최대한 자동편하지만 잘못 고칠 위험이 있습니다.
결정 B

미제출자 확인을 처음 버전에 넣을까요?

넣는다 (추천)대상자 이름 명단만 한 번 붙여 넣으면 됩니다. 서버가 필요 없습니다.
나중에처음 기획대로 뺍니다.
결정 C

한 파일에 여러 사람 몫이 오는 경우가 있나요?

거의 없다 (추천)파일 하나 = 제출자 한 명으로 둡니다.
자주 있다양식에 줄마다 쓰는 "대상자" 칸을 두고, 중복 판단도 줄 단위로 바꿉니다.
결정 D

옛날 엑셀(.xls)이나 CSV로 회신하는 사람이 있나요?

거의 없다 (추천).xlsx만 받고, 다른 형식은 "다시 저장해서 보내 주세요"라고 알려 줍니다.
있다읽기 부품을 하나 더 넣어서 .xls와 .csv도 엽니다.
