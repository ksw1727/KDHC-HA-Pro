# 02. 생성 파트 — 한난MOA 양식 빌더와 엑셀 생성 (개발자 1)

> 함께 읽을 문서: `00-overview.md`, `01-contract.md`
> 담당 코드: `src/generator/`, `src/contract/layout/`(1단계 작성, 이후 공동 소유) (+ `fixtures/` 생성 스크립트)
> 금지: `src/aggregator/` import, `src/contract/` 단독 수정

---

## 1. 이 파트가 하는 일

운영자가 웹 화면에서 양식을 정의하면, **실시간 미리보기**(빈 양식 / 취합본 모양)를 보여주고, 공통 계약에 맞는 **엑셀 파일**(지사별 zip 또는 단일 파일)과 **양식 JSON**을 내보낸다.

하지 않는 일: 제출된 파일 읽기, 검증, 취합.

## 2. 화면

**화면 위치**: 양식 만들기는 따로 탭이 없다. [AI로 만들기] 화면이 **대화(약 80%) + 오른쪽 설정 패널(약 20%)**이고, 패널에는 빌더의 **①~⑤ 설정만** 있다(`src/generator/FormPanel.tsx`, `BuilderPage compact`). 위쪽 메뉴는 [AI로 만들기]·[취합하기] 두 개. 목업: `docs/mockups/chat-side-panel.html`.

- **미리보기는 대화 속 마지막 양식 카드 하나**다. 패널에서 고칠 때마다(자동 저장을 기다리지 않고) 카드 미리보기가 바로 바뀌고, 달라진 칸이 잠깐 노랗게 반짝인다. 카드 머리글을 누르면 패널에서 그 항목이 열리고, 패널에서 고른 항목은 카드에 파란 테두리로 보인다.
- 패널이 여는 양식: AI가 새로 만든 양식(저절로), 카드의 [패널에서 고치기], 새로고침하면 대화의 마지막 양식. 열린 양식이 없으면 안내 + [양식 파일 열기]·[엑셀에서 양식 되살리기]·[빈 양식 만들기](구조 고르기). 여기서 연 양식은 대화에 카드로 붙고, 다음 말에 AI에게 함께 넘긴다.
- **[크게 열기]**: 미리보기·그리는 판이 있는 예전 2단 빌더를 화면 전체로 띄운다([← 패널로 돌아가기]). 자유 제작형은 판에 그려야 해서 ③에서 이 버튼을 안내한다.
- 위쪽 **[양식 설정 패널] 스위치**로 켜고 끈다(처음엔 켜짐). 왼쪽 경계를 끌어 너비를 바꾸고, 두 번 누르면 기본 너비(화면의 22%, 360~520px)로. 패널은 340px, 대화는 480px 밑으로 줄지 않는다. 켬/끔과 너비는 브라우저에 기억한다.
- 구조 고르기 첫 화면(2.1)은 없앴다. 구조는 AI가 고르거나 ② 양식 구조·[빈 양식 만들기]에서 고른다.

### 2.1 첫 화면 (없앰 · 10.22)

구조 카드·질문으로 고르기·최근 양식이 있던 첫 화면(`LandingPage`)은 없앴다. 목업 기록: `docs/mockups/generator-landing.html`.

- 새 양식은 대화로 시작하거나, 설정 패널의 **[빈 양식 만들기]**(구조 고르기)로 시작한다.
- [양식 파일 열기]·[엑셀에서 양식 되살리기]는 설정 패널의 빈 상태와 빌더 버튼 줄에 있다(`storage/openForm.ts`).
- 최근 양식 목록·복제는 없앴다. 지난 양식은 [양식 파일 저장]으로 받아 둔 .form.json이나 내보낸 엑셀로 다시 연다.
- 빌더 안 ② 양식 구조에서 다른 구조를 고르면, 바꾸기 전에 작은 창에 그 구조의 3컷 이야기(`builder/StructureStory.tsx`: ① 배포 양식 → ② 지사가 작성 → ③ 취합본)와 "지워지는 항목"을 보여주고 확인을 받는다.

### 2.2 빌더 화면 (2단 구성)

```
┌──────────────────────────────────────────────────────────────────┐
│ 양식 제목                               [양식 파일 저장] [엑셀 내보내기] │
├──────────────────────┬───────────────────────────────────────────┤
│ ① 기본 정보           │  미리보기  [빈 양식 | 취합본]   지사: [서울▼]   │
│ ② 양식 구조           │  ┌───────────────────────────────────────┐ │
│ ③ 항목·서식 (블록별)   │  │ 엑셀처럼 생긴 표                        │ │
│ ④ 취합 방식           │  │ 잠긴 칸 / 입력칸 / 필수칸 / 자동 칸 표시  │ │
│ ⑤ 지사/기관           │  └───────────────────────────────────────┘ │
└──────────────────────┴───────────────────────────────────────────┘
```

| 영역 | 내용 |
|---|---|
| ① 기본 정보 | 제목(필수), 작성 안내(예: "11월 5일까지 회신"), 제출 기한(날짜 — 내 업무공간 달력에서 막대가 끝나는 날), 문의처. 작성 안내 아래에 **고정 안내** "입력칸만 쓸 수 있어요. 참고 사항은 칸에 엑셀 메모로 달고, 계산이 필요하면 새 시트를 추가해 쓰세요."가 항상 붙는다(지울 수 없음, 시트 모으기형 제외) |
| ② 양식 구조 | 목록형 / 표형 / 혼합형 / 빈칸채우기형 / 시트 모으기형. 바꾸면 블록을 해당 구조로 재구성하고, 기존 항목은 가능한 한 유지(이동 불가한 항목은 확인 창) |
| ③ 항목·서식 | 블록별 항목 목록. 추가·삭제·끌어서 순서 변경(dnd-kit). 항목을 누르면 편집 패널(2.3). 목록 블록은 **입력 줄 수**(기본 100)와 **예시 줄**(선택). 표형은 행 제목·열 제목 목록, 합계 행·합계 열 여부. 빈칸채우기형은 표 편집기(2.4). 시트 모으기형은 이 영역이 "시트 시작 모양"으로 바뀐다(2.5) |
| ④ 취합 방식 | 평소에는 한 문장 요약("한 표로 모으고, 제출 현황도 만들어요") + [바꾸기]. 자유 제작형에서 고른 방식에 문제가 있으면 처음부터 펼친다. 펼치면 `AGGREGATION_SUPPORT`에서 현재 layout·지사 방식이 지원하는 방식만 체크박스로. `AGGREGATION_REQUIRED`는 체크 고정(같은 틀 시트, 표형의 지사별 펼치기, 시트 모으기형의 시트 모으기). 기본값: 필수 + 제출 현황표(지사 사용 시) |
| ⑤ 지사/기관 | **제출처를 부르는 말**(지사 / 부서 / 기관 / 직접 입력, 기본 지사 → `org.label`)을 먼저 고른다. 이후 화면·엑셀 칸 이름·결과 시트가 이 말로 바뀐다(예: "부서명"). [목록 있음 / 지사명 입력 / 식별 안 함] (시트 모으기형은 지사명 입력 없음). 목록 있음: 텍스트 영역에 붙여넣기(줄바꿈 또는 탭 구분) 또는 xlsx/csv 첫 열 불러오기. 중복·빈 줄 자동 제거, 개수 표시. 지사명 입력에서도 참고 목록을 넣으면 지사명 칸이 드롭다운. 식별 안 함: "파일 하나를 응답 하나로 취합합니다. 필요하면 `부서` 같은 칸을 직접 추가하세요" 안내 |

**미리보기**
- 칸을 고치면 즉시 반영.
- **[빈 양식 | 취합본] 전환**: 취합본 모양은 `layoutSheet(schema, { mode: 'aggregate', … })`에 가짜 데이터 3줄(지사 3곳)을 넣어 그린다. 자동 칸(`지사`·`출처 파일`·`원본 줄`·`상태`), 표형 합계, 빈칸채우기형 겹침 결과를 확인할 수 있다.
- 목록 블록은 처음 5행 + "… (총 100행)" 줄로 줄여 보여준다.

**입력 검증 (내보내기 전)**: 제목 없음, 항목 0개, 같은 블록 안 이름 중복, 목록 선택의 선택지 없음, 패턴 종류 없음, min > max, preset인데 지사 0개, 표형 행·열 제목 없음, 빈칸채우기형 입력칸 0개이고 여유 줄 0 → 해당 위치에 빨간 안내. [엑셀 내보내기]를 누르면 먼저 검사하고, 문제가 있으면 **검사 창**에 목록(위치 · 내용 · [고치러 가기])을 보여준다. [고치러 가기]는 빌더의 해당 영역을 펼치고 항목을 빨갛게 표시한다. 버튼을 비활성화하지 않고 누른 뒤에 이유를 알린다(2.6 ①).

### 2.3 항목 편집 패널 (서식 설정)

공통: 이름, 타입, 필수, 안내(엑셀 입력 메시지).

**처음에는 꼭 정할 것만 펼친다** (사용성 개선, 2026-10-21): 이름 · 타입 · 필수 한 줄과, 서식 한 줄 요약("원 단위 · 천 단위 쉼표 · 이렇게 보여요 1,000원") + [▸ 자세히]. 아래 표의 서식·작성 안내·정리 안내는 [자세히] 안에 있다. 목록에서 고르기(선택지)와 형식(휴대폰 등)은 처음부터 정해야 해서 서식을 펼쳐 두고, 작성 안내만 접는다. 다른 항목을 고르면 다시 접힌다.

| 타입 | 서식 설정 | 미리보기 예 |
|---|---|---|
| 텍스트 | 최대 글자 수 | `홍길동` |
| 숫자 | 정수 / 소수(자릿수 1~4), 천 단위 쉼표(기본 켬), 단위(개·원·명·% 또는 직접 입력), 최소~최대 | `1,000개`, `12.50%` |
| 날짜 | 표시 형식(`2026-11-01` / `2026.11.01` / `2026-11` 연월 / `2026` 연도), 허용 범위(날짜 지정 또는 "오늘 이후", "오늘부터 30일 이내" 같은 상대값) | `2026.11.01` |
| 목록 선택 | 선택지(줄바꿈으로 입력, 중복 제거) | 드롭다운 |
| 메모 | 없음(줄바꿈 표시) | 여러 줄 |
| 패턴 | 전화번호 / 휴대폰 / 이메일 / 사업자번호 | `010-1234-5678` |
| 계산 | 계산식(아래), 결과 서식(정수/소수, 쉼표, 단위). 필수·입력 규칙 없음, 잠긴 칸 | `= [수량] × [단가]` |

- 서식 옆에 "취합할 때 `1,000개`, `₩1000`처럼 들어와도 숫자 1000으로 정리돼요" 같은 한 줄 설명을 보여준다(`01-contract.md` 5절 표 기반).

**계산식 편집기** (`FormulaEditor`, `01-contract.md` 3.1절) — 버튼과 직접 입력 둘 다
- 글자 입력칸 + 버튼 묶음: 쓸 수 있는 칸 이름(파란 칩), 목록 칸(합계 등 안에서만, 초록 칩), `+ − × ÷ ( ) ,`, ⌫·모두 지우기, `합계( ) 평균( ) 최소( ) 최대( ) 반올림( ) 조건( )`, 비교 `≥ > ≤ < = ≠`, 숫자·글자 넣기. 버튼은 커서 위치에 끼워 넣는다.
- 아래 한 줄: 오류(빨강) 또는 "예시(남=10, 여=20)로 계산하면 66.667"(파랑).
- 넣을 수 있는 곳: 목록·혼합형 항목 타입 `계산`, 위쪽 정보 항목 `계산`(목록 열 합계 등), 표형 **계산 열·계산 행**(③ 아래 목록, + 추가), 빈칸채우기 [계산 칸으로] 버튼과 여유 줄 열 타입 `계산`.
- 미리보기: 빈 양식은 계산 칸에 `= 계산식`을 흐리게, 취합본은 계산한 값.

### 2.4 빈칸채우기형 표 편집기

```
┌────────┬────────┬────────┬────────┬────────┐
│ 사업    │ 예산    │ 서울    │ 부산    │ 대구    │  ← 머리글 (편집 가능)
├────────┼────────┼────────┼────────┼────────┤
│ 교육    │ 900    │ [입력]  │ [입력]  │ [입력]  │  ← 칸마다 고정 / 입력 / 빈칸
│ 홍보    │ 600    │ [입력]  │ [입력]  │ [입력]  │
├────────┴────────┴────────┴────────┴────────┤
│ 여유 줄: [ 5 ]줄   (작성자가 행을 추가할 수 있는 영역)      │
└──────────────────────────────────────────────┘
```

- 행·열 추가·삭제. 칸에 값을 직접 입력하면 **고정 칸**이 된다.
- **엑셀에서 복사한 표를 붙여넣기**(클립보드 탭 구분 텍스트)로 본문을 한 번에 채울 수 있다. 서식·병합은 가져오지 않는다(외부 양식 표준화는 로드맵).
- 칸이나 범위를 선택하고 [계산 칸으로] → 계산 칸(계산식은 비어 있음). [입력칸으로] → 선택한 칸 모두 같은 항목 설정(타입·서식·필수)으로 지정. 입력칸 이름은 자동으로 `{행 첫 칸} · {열 머리글}`(예: `교육 · 서울`), 바꿀 수 있다.
- 여유 줄 수(기본 0)를 정하면 열마다 타입·서식을 지정하는 `spareColumns` 편집 줄이 나타난다.
- **작성처** (⑤ 제출처가 목록일 때): 입력칸마다 어느 제출처가 채우는지 정한다. 제출처마다 자기 영역이 미리 정해진 표라서 칸이 겹치면 안 된다. 제출처는 용도에 따라 지사·부서·담당자 등 무엇이든 된다(⑤에서 부르는 말과 목록을 정한 대로).
  - 이때 ④ 취합 방식에 펼치기는 나오지 않는다(같은 틀 시트 한 장에 모두 모이므로).
  - 열 머리글이나 행 첫 칸이 제출처 이름과 같으면 자동(`● 강남지사 (자동)`). 다른 칸은 입력칸을 골라 [작성처 ▼]에서 직접 지정, [머리글로 자동]으로 되돌린다.
  - 표 아래 작성처 줄에 제출처별 색과 칸 수, 칸이 하나도 없는 제출처는 "(칸 없음)".
  - 내보내기 전 검사: 작성처가 없는 입력칸이 있으면 오류.
  - 제출처마다 받는 파일에서 자기 칸만 열리고, 다른 제출처 칸은 회색·잠금. 안내문에 "회색으로 잠긴 칸은 다른 지사가 채우는 칸이니 자기 칸만 작성해 주세요"가 붙는다.

### 2.5 시트 모으기형 설정

칸 규칙 없이 제출처가 시트를 자유롭게 작성하고, 취합 때 시트를 그대로 한 파일에 모으는 구조다(예: 지사별 안전점검 결과 보고서, 부서별 추진 실적 보고). 빌더 ③이 아래로 바뀐다.

| 설정 | 선택지 | 기본 |
|---|---|---|
| 시트 시작 모양 | 빈 시트로 보내기 / **제작한 양식으로 보내기**(빌더 안 표 그리기: 칸에 글자를 넣으면 제목·안내 칸, 비워 둔 칸은 작성 자리. 행·열 추가·삭제, 엑셀에서 복사한 여러 칸을 칸 하나에 붙여넣으면 그 칸부터 채움) | 빈 시트 |
| 취합할 때 모을 시트 | **보고서 시트만** / 파일 안의 모든 시트(제출처가 추가한 시트 포함) | 보고서 시트만 |

- 미리보기: 1행 제목, 2행 제출처명·안내, 4행부터 제작한 양식(글자 칸 = 회색 굵은 제목 칸, 빈칸 = 테두리 있는 작성 자리). 그 아래에 "여기부터 자유롭게 작성" 표시. [취합본] 전환은 `목차 · 서울 · 부산 · 대구` 시트 탭 모양으로 보여준다.
- 화면 안내: "모양을 자유롭게 고칠 수 있어서 칸 검사는 하지 않아요. 시트를 그대로 모아 드려요." / "사진·도형은 아직 옮겨지지 않아요."
- 지사 방식은 목록 있음 / 식별 안 함만 고를 수 있다(`01-contract.md` 3절).

### 2.7 자유 제작형 (그리는 판)

쓰던 서식을 그대로 옮기고 싶을 때 쓰는 구조다. **오른쪽 미리보기가 곧 그리는 판**이 되고, 왼쪽 ③은 "고른 영역"이 된다. 목업: `docs/mockups/generator-free.html`. 계약은 `01-contract.md` 3.2.

| 동작 | 방법 |
|---|---|
| 글자 쓰기 | 칸을 고른 뒤 바로 타자(한글 포함), 두 번 누르기·Enter·F2로 고치기. Enter = 저장하고 아래 칸으로, Esc = 취소, Delete = 글자 지우기. 고른 칸에 늘 보이지 않는 입력칸을 두어 한글 조합이 깨지지 않게 한다 |
| 칸 고르기 | 끌어서 여러 칸, 방향키·Shift+방향키. 영역 칸을 누르면 영역 전체 선택. **화면·안내 문구의 칸 주소는 판 좌표가 아니라 미리보기(엑셀) 행 번호로 적는다** |
| 입력 칸 | 고른 칸마다 값 하나. 왼쪽 글자 칸이 이름이 된다(없으면 "입력 칸 n") |
| 입력 줄 영역 | 맨 윗줄 = 머리글(그 줄 글자가 칸 이름), 아래 줄 수 = 입력 줄 수 |
| 숫자 표 | 2행 2열 이상. 맨 윗줄 = 열 제목, 맨 왼쪽 열 = 행 제목, 왼쪽 위 글자 = 표 이름 |
| 칸 합치기 / 풀기 | 글자 칸끼리만. 입력 영역은 합칠 수 없다 |
| 지정 풀기 | 줄 영역·숫자 표를 풀면 머리글·제목이 글자 칸으로 돌아온다 |
| 옮기기 | 영역을 고르고 [↦ 옮기기] → 옮길 왼쪽 위 칸 누르기 |
| 행·열 | [+ 행] [− 행] [+ 열] [− 열] (영역이 있는 행·열은 줄일 수 없다) |

- 판 위 1~5행(흐리게)은 제목·안내·제출처 자리다(① ⑤에서 정함).
- 영역 색: 입력 칸 파랑, 입력 줄 영역 초록, 숫자 표 보라. 줄 영역·숫자 표에는 이름표를 늘 붙이고, 입력 칸 이름표는 골랐을 때만 보인다.
- **③ 고른 영역**: 입력 칸 = 항목 편집(이름·타입·서식·필수·안내), 입력 줄 영역 = 영역 이름 + 머리글 칸 목록 + 줄 수·예시 줄, 숫자 표 = 영역 이름 + 표형 편집기. 아무것도 안 골랐으면 사용법과 지정한 영역 목록.
- **④ 취합 방식 검사**: 방식마다 ✓ 가능 / ! 고치면 됨 / ✕ 이 양식으론 안 됨과 이유 한 줄, 고칠 것 한 줄, [고치러 가기](판에서 그 영역을 골라 줌)·[방식 빼기]. 고칠 것이 있으면 ④ 제목에 "고칠 것 n", 내보내기 전 검사 창에도 같은 문구가 나오고 내보내기를 막는다.
- 다른 구조 → 자유 제작형: 항목:값은 [이름 | 입력 칸] 줄로, 목록·표는 그 아래로 차례로 놓는다. 빈칸채우기 표는 옮기지 않는다.

### 2.6 내보내기

[엑셀 내보내기]를 누르면 **검사 → ① 일정 정보 → ② 확인 창 → ③ 완료 화면** 순서로 진행한다. 창 제목 옆에 ①·②·③ 단계를 보여 준다. 목업: `docs/mockups/generator-start-export.html` 3~5번, 받을 파일 고르기는 `docs/mockups/export-file-choice.html`, 일정 정보는 `docs/mockups/export-schedule-info.html`.

- **대화 카드의 [엑셀 내보내기]도 같은 창**을 쓴다(버튼은 마지막 양식 카드에만)(`hanan-moa:export-form` → 설정 패널이 그 양식을 열고 창을 띄움). 그래야 기한을 묻고 내보낸 기록(`lastExported`)이 남아, 내 업무공간 취합 일정에 "기다리는 양식"으로 뜬다.

**검사**: 2.2 입력 검증. 통과하지 못하면 검사 창을 띄우고 멈춘다.

**① 일정 정보** (`ExportFlow` 안 `ScheduleInfo`, 계산은 `state/schedule.ts`): 내 업무공간 취합 일정(달력)은 양식의 **제출 기한**으로 막대를 그린다. 기한이 **비었거나 이미 지났을 때만** 이 단계를 보여 주고, 오늘 이후 기한이 들어 있으면 건너뛴다.
| 항목 | 내용 |
|---|---|
| 안내 | "내 업무공간 취합 일정에 올리려면 제출 기한이 필요해요. 엑셀 안내 줄과 보낼 안내문에도 들어가요" |
| 지난 기한 | 노란 상자 "들어 있던 기한 10/10(금)은 이미 지났어요. 지난 차수 양식이면 새 기한을 골라 주세요" (입력칸은 비워 둠) |
| 제출 기한 | 날짜 입력(오늘 이후) + 빠른 버튼 **3일 뒤 · 1주 뒤 · 2주 뒤 · 이번 달 말**(말일이면 다음 달 말). 고르면 "✓ 10/30(금)까지 · 오늘부터 7일" |
| 문의처 | 선택. 엑셀 안내 줄·안내문에 들어감 |
| 제출처 | preset이면 "지사 15곳 ✓"만 보여 줌(비었으면 이미 검사에서 막힘) |
| 버튼 | 작은 링크 [기한 없이 내보내기](상시 취합용, 취합 일정에는 "기한 없음") / [취소] / [다음 →](기한을 골라야 켜짐) |
- 여기서 넣은 값은 `meta/set`으로 양식에 저장한다 → 설정 패널 ①·대화 카드·자동 저장에 바로 반영. 기한만 바뀌므로 버전은 그대로.
- AI는 사용자가 기한을 말하지 않으면 `deadline`을 지어내지 않고 비워 둔다(`tools/ai/skills/excel-form.md`).

**② 확인 창**
| 항목 | 내용 |
|---|---|
| 요약 | 양식 이름·구조, 제출 기한(예: 10/30(금), 없으면 "기한 없음" + 취합 일정 안내)·문의처와 [바꾸기](① 일정 정보로). 제출처 목록이 없으면 "엑셀 1개" |
| 받을 파일 | 제출처 목록이 있을 때(preset)만. **[{제출처}별 파일 n개 (압축 파일 1개)] 추천·기본** / **[공용 파일 1개]** (아래 "공용 파일") |
| 버전 안내 | 칸 구조가 바뀌었으면 노란 상자로 "v1 → v2, 바뀐 것: 교육비 항목 추가, 직급 선택지 변경. 이미 보낸 v1 파일이 돌아오면 취합할 때 알려 드려요". 안 바뀌었으면 회색으로 "v1 그대로 내보내요" |
| 파일 이름 | zip 이름과 안의 파일 이름 2개 + "… n개 더" |
| 파일마다 들어가는 것 | 입력 규칙, 제목 줄·지사명 잠금, 작성 안내 메시지, 인쇄 영역, 숨김 시트, 틀 고정 (시트 모으기형은 "자유롭게 고칠 수 있는 시트"와 숨김 시트만). 빈칸채우기형에 작성처가 있으면 지사별 파일은 "다른 지사 칸은 회색·잠금", 공용 파일은 "모든 지사 칸이 열려 있음" |
| 양식 파일 함께 저장 | 체크박스, 기본 켬. "다음 차수에 다시 쓰거나, 숨김 정보가 사라진 파일을 살릴 때 필요해요" |
| 버튼 | [미리보기로 돌아가기] / [내보내기 (15개 · zip)] (공용 파일이면 [내보내기 (1개)]) |

**공용 파일** (preset 양식을 모두에게 같은 파일 1개로 보내기)
- 지사명 칸(B4)을 잠긴 값 대신 **필수 입력칸 + 제출처 목록 드롭다운**으로 만든다. 메타 `orgName`·파일 속성 `kdhc.org`는 넣지 않는다. 양식 정보(`org.mode`)는 preset 그대로 둔다(취합에서 미제출 표시가 유지되도록).
- 취합은 바꾸지 않는다: 메타에 제출처가 없으면 지사명 칸 값을 읽는다. 비어 있으면 "제출처 확인", 같은 이름이 둘이면 중복 질문이 뜬다.
- 빈칸채우기형(작성처 있음): 누가 쓸지 몰라 다른 제출처 칸을 잠그지 않는다. 고르면 주황 경고 "다른 지사 칸이 잠기지 않아요… 지사별 파일을 권해요". 취합은 그대로 작성처 파일의 값만 쓴다.
- 시트 모으기형: 제출처를 파일 속성으로만 알아내므로 공용 파일을 고를 수 없다(흐리게 + 이유 한 줄).
- 안내문에 "먼저 {제출처}명 칸에서 자기 {제출처}를 꼭 골라 주세요."를 넣고, "미리 들어 있으니…" 문장은 뺀다. 빈칸채우기형은 "회색으로 잠긴 칸은…" 대신 "다른 {제출처}가 채우는 칸은 비워 두고 자기 칸만 작성해 주세요.".

**③ 완료 화면**
- "엑셀 15개를 만들었어요"와 내려받은 파일(zip, 양식 파일) 카드. 각 카드에 [다시 받기](화면을 닫기 전까지 다시 만들지 않고 같은 파일을 받음). zip 안 파일 목록 미리보기.
- 파일 카드 아래 한 줄: "**내 업무공간 취합 일정**에 올라갔어요 · 오늘 → 10/30(금)까지 (7일)"(기한이 없으면 "기한 없음") + [일정 보기](내 업무공간 탭으로).
- **이제 이렇게 하세요** 3단계: ① 지사에 파일 보내기 ② 돌아온 파일 모으기("파일 이름이 바뀌어도 괜찮아요") ③ 취합하기 [취합하기로 이동 →](이 양식이 선택된 상태로 취합하기 탭을 연다).
- **안내문 복사**: ①단계 아래에 지사에 보낼 안내문을 만들어 보여주고 [안내문 복사]로 클립보드에 복사한다. 프로그램이 메시지를 보내지는 않는다(메일 자동 발송 없음 원칙 유지). 기본 문구:
  > [{제목}] 첨부 파일을 작성해 **{제출 기한 M월 D일}까지** 회신 부탁드립니다. MS Excel 또는 한셀로 작성해 주세요. 노란 칸은 꼭 채워 주시고, 칸 이름과 순서는 바꾸지 말아 주세요. 참고 사항은 칸에 엑셀 메모로 달아 주시고, 계산이 필요하면 새 시트를 추가해 써 주세요. 문의: {문의처}
  - "MS Excel 또는 한셀로…" 문장은 항상 넣는다(Numbers 등은 입력 규칙·보호를 지원하지 않음).
  - 기한·문의처가 비어 있으면 그 문장을 뺀다. 시트 모으기형은 "노란 칸…"·"참고 사항은…" 두 문장 대신 "보고서 시트에 자유롭게 작성해 주세요."를 쓴다. `{제출처 부르는 말}`에 맞춰 "지사"/"부서"로 바꾼다.
  - 복사 전에 문구를 고칠 수 있는 입력칸으로 보여준다.

**파일 규칙**
- preset 모드: 지사마다 `{양식제목}_v{버전}_{지사명}.xlsx`를 만들어 `{양식제목}_v{버전}_배포용.zip`으로 다운로드
- input·none 모드, preset 공용 파일: `{양식제목}_v{버전}.xlsx` 1개
- 파일명에 쓸 수 없는 문자(`\/:*?"<>|`)는 `_`로 바꾼다.
- **칸 구조**(항목 추가·삭제·순서·타입·서식·선택지, 블록 구조, 표 칸 종류)를 바꾼 뒤 다시 내보내면 `formVersion`을 1 올린다. 제목·안내 문구·기한만 바뀌면 유지한다. `formId`는 유지한다. 단, 같은 `formId`의 저장본·내보내기 기록이 **다른 양식**(제목이 다르고 항목 key가 절반 넘게 다름)이면 버전 판단에 쓰지 않는다. AI 대화에서 전혀 다른 양식을 새로 만들면 새 `formId`·v1로 시작한다.
- **[양식 파일 저장]**(빌더 상단 버튼, 확인 창 체크박스): `{양식제목}.form.json` (= `FormSchema` 그대로)

## 3. 핵심 구조: 미리보기와 파일이 반드시 같게

```
FormSchema ─► contract/layout.layoutSheet(schema, input) ─► SheetModel ─┬─► <PreviewGrid/>  (HTML)
                                                                         └─► writeWorkbook()  (ExcelJS) ─► xlsxPatch ─► Blob
                                                                                └─ CellMap도 SheetModel에서 추출
```

- `layoutSheet`는 **순수 함수**(입력이 같으면 출력이 같음, 화면·파일 접근 없음)로 만든다. 테스트의 중심이다. 계약 위치(`src/contract/layout/`)에 두는 이유는 취합 파트가 같은 틀 시트를 만들 때 같은 함수를 쓰기 때문이다(`01-contract.md` 7절).
- `PreviewGrid`와 `writeWorkbook`은 `role`별 스타일 표(`contract/layout/styles.ts`) 하나를 공유한다.
- 생성 파트는 `mode: 'template'`을 주로 쓰고, 미리보기의 [취합본] 전환에서만 `mode: 'aggregate'`를 가짜 데이터로 호출한다.

| label / header | 굵게, 연회색 배경, 테두리. 필수면 이름 뒤 ` *`와 머리글 색 강조 | 잠금 |
| input | 흰 배경, 테두리. 필수면 연노랑 배경. 서식(`excelNumFmt`) 적용 | **잠금 해제** |
| example | 회색 기울임 글자, 첫 입력 줄. 작성자가 덮어써도 됨 | **잠금 해제** |
| fixed | 빈칸채우기형 고정 내용. 일반 글자, 연회색 테두리 | 잠금 |
| locked-value | 회색 글자 (preset 지사명) | 잠금 |
| row-number | 회색, 가운데 | 잠금 |

- 항목 타입별 입력 규칙과 서식은 `FIELD_TYPES[type].excelValidation()`, `excelNumFmt()`를 사용한다(직접 만들지 않는다).
- 안내(`help`)는 데이터 유효성 검사의 입력 메시지(`showInputMessage`, `prompt`)로 넣는다.
- 오류 메시지: `showErrorMessage: true`, 스타일 `stop`, 메시지 "{항목명}: {규칙 설명}" (예: "참가일: 날짜를 입력하세요 (예: 2026-10-20)", "수량: 0 이상 999 이하의 정수를 입력하세요")
- 표형 합계 행·열: `SUM` 수식(잠금). 작성자 화면에서 바로 합계가 보인다.
- **인쇄영역**: `SheetModel.printArea`(제목 ~ 입력 영역 끝)를 `worksheet.pageSetup.printArea`로 설정. 가로 방향, 너비 1페이지 맞춤.
- 시트 보호: `worksheet.protect(PROTECT_PASSWORD, { selectLockedCells: true, selectUnlockedCells: true, formatCells: false, insertRows: false, deleteRows: false })` — 입력칸만 편집 가능. `objects`는 `false`로 주지 않는다(작성자가 **엑셀 메모**를 넣을 수 있어야 함, `01-contract.md` 4.3)
- 틀 고정: list·grid 블록 머리글 행 아래로 고정
- 메타: `contract/metaIO.writeMeta()` 호출 (`kind: 'submission'`, `orgName`, `sheetName`, `cellMap`, checksum 포함)
- 후처리: `contract/xlsxPatch` (파일 속성). 통합문서 구조 보호는 넣지 않는다(작성자가 계산용 시트를 추가할 수 있게, `01-contract.md` 4.3)
- 통합문서 속성: `creator = 'KDHC-HA-Pro'`
- **시트 모으기형 예외**: 시트 보호·입력 규칙·인쇄영역·틀 고정을 넣지 않는다(셀 합치기와 시트 추가를 막지 않기 위해, `01-contract.md` 4.3). 보고서 시트 이름은 `보고서`. `_meta`(veryHidden)와 파일 속성 이중 기록은 똑같이 넣는다. `cellMap`은 없다.

## 6. fixtures 생성 스크립트

`npm run fixtures`로 `fixtures/`의 파일을 만든다. 생성 파트 코드(`layoutSheet`, `writeWorkbook`)로 정상 파일을 만든 뒤 ExcelJS로 값을 채우고, 상황별로 변형한다(열 순서 바꾸기, `_meta` 삭제, 메타 JSON 수정, 줄 숨기기, 취소선, 셀 병합, 단위 붙은 값, 합계 줄 추가 등).
**0단계에서는 생성 파트가 아직 없으므로**, 이 스크립트의 첫 버전은 ExcelJS로 직접 배치를 만들어 계약만 지키면 된다. 개발자2 프로토타입의 `selfcheck.js` 회신 세트를 `messy__*`로 옮긴다. 2단계에서 실제 생성 코드로 바꾼다.

## 7. 완료 기준

1. 여섯 가지 구조 각각으로 양식을 만들어 내보낼 수 있다. 시트 모으기형 파일은 엑셀에서 셀 합치기·시트 추가가 막히지 않는다.
2. 미리보기의 칸 배치와 내보낸 파일의 칸 배치가 같다(테스트로 확인).
3. 내보낸 파일을 MS Excel에서 열면: 입력칸만 편집 가능(인쇄영역 밖 포함 나머지는 잠김), 입력칸에 엑셀 메모 넣기 가능, 새 시트 추가 가능, 드롭다운·숫자·날짜 제한 동작, 숫자 서식(쉼표·단위) 표시, 안내 메시지 표시, 인쇄영역 설정됨, `_meta` 시트가 보이지 않음.
4. preset 15개 지사 → zip 안에 파일 15개, 각 파일의 지사명 칸과 메타 `orgName`이 일치.
5. 양식 파일 저장 → 불러오기 → 같은 파일이 생성된다. 빈 양식 xlsx에서 되살리기 → 같은 `FormSchema`.
6. 빈칸채우기형: 엑셀에서 복사한 표를 붙여넣고 입력칸·여유 줄을 지정해 내보낼 수 있다.
7. 내보내기 중 네트워크 요청이 없다.

## 8. 테스트

|---|---|
| `layoutSheet` | 구조 4종 × (preset/input/none) × (template/aggregate) + 시트 모으기형 × (preset/none) × (빈 시트/기본 틀) 스냅샷. `cellMap`의 모든 주소가 `cells`에 존재. `printArea`가 입력 영역을 모두 포함 |
