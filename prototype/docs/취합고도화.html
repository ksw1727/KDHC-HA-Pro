사람 눈으로 한 번 더 보기

지난 보완(칸 맞추기, 값 정리, 개정본, 검산)으로 "양식에서 조금 벗어난 파일"은 다룰 수 있게 됐습니다. 이번에는 꼼꼼한 담당자가 원본 파일을 열어 놓고 하나씩 대조하면서 잡아내는 것들을 정리했습니다.

모양은 달라도 사람은 뜻을 압니다

  • 숨긴 줄, 취소선

🧠 내용이 말이 되나

형식은 맞아도 내용이 이상한 것

  • 겹치면 안 되는 값이 겹침 (자산번호 등)
  • 같은 줄을 두 번 적음
  • 시작일이 종료일보다 늦음, 금액 ≠ 수량×단가
  • 범위를 벗어난 값, 단위 착각(원/천원)

🔁 무엇이 바뀌었나

수정본을 받으면 사람은 비교합니다

  • v1 → v2에서 바뀐 줄 표시
  • 지난 취합본 대비 추가·변경·삭제
  • 옛날 양식 버전으로 낸 파일 흡수

📋 결과 정리

취합 직후 사람이 꼭 하는 일

  • 내가 내린 판단 기록 남기기
  • 보기 좋은 순서로 정렬

빈 회신

내용 없이 돌아온 파일

사람은 "이 팀은 신청할 게 없구나"라고 이해합니다. 지금은 0줄이라 파일목록에서 묻힙니다. → 상태를 "제출함 · 해당 없음"으로 따로 표시합니다. 원하면 양식에 "해당 없음" 체크칸을 넣을 수 있습니다.

수식 칸

수식으로 계산된 값

결과 값만 가져옵니다. 다른 파일을 참조하던 수식이 깨져 있으면(#REF!) 오류로 표시하고, 원래 수식은 메모로 남깁니다.

3내용이 말이 되나: 양식에 "검사 규칙" 더하기

사람은 "자산번호가 두 번 나왔네", "끝나는 날이 시작보다 빠르네"를 알아챕니다. 이런 검사는 양식을 만들 때 칸 설정에 몇 가지를 더하면 웹페이지가 대신할 수 있습니다.

칸 이름금액 종류숫자 ▾ 꼭 입력☑ 허용 범위새0 ~ 5,000,000 겹치면 안 됨새☐ (자산번호·사번 같은 칸에 체크) 계산 확인새수량 × 단가 와 같아야 함 날짜 순서새(날짜 칸에서) "종료일"보다 빠르거나 같아야 함

취합할 때 잡아내는 것

  • 겹치면 안 되는 값: 자산번호 A-102가 영업팀과 개발팀 파일에 둘 다 있음 → 오류 두 줄 모두 표시
  • 같은 줄 두 번: 한 파일 안에서 모든 칸이 똑같은 줄 → 확인 필요 실수로 복사했을 수 있음
  • 계산 불일치: 금액 ≠ 수량 × 단가 → 오류
  • 날짜 순서: 종료일이 시작일보다 빠름 → 오류
  • 범위 밖: 수량 -1, 금액 50억 → 오류
  • 단위 착각: 다른 파일들은 수백만 원대인데 한 파일만 수천 → "천 원 단위로 적었나요?" 확인 권장

원본과 나란히 보기

파일목록에서 파일을 누르면 왼쪽에 원본, 오른쪽에 취합된 결과가 나란히 보입니다. 뺀 줄, 고친 칸, 오류 칸이 같은 색으로 연결돼서, 엑셀 파일을 하나씩 열어 대조하는 일을 대신합니다.

7확인할 사항

아래 답에 따라 어떤 기능이 필요한지가 달라집니다.

질문 1 · 가장 중요

실제 회신 파일 샘플을 받을 수 있을까요?

개인정보를 지운 회신 파일 5~10개면 충분합니다. 실제로 자주 나오는 실수를 보고 우선순위를 정하고, 그대로 시험 자료로 씁니다.

질문 2

취합한 다음 보통 무엇을 하시나요?

합계·건수 집계, 피벗, 보고서 붙여 넣기 등. 답에 따라 "요약 시트"를 어떻게 만들지 정합니다.

질문 3

겹치면 안 되는 값이 있는 양식이 있나요?

사번, 자산번호, 주문번호 등. 있다면 "겹치면 안 됨" 설정을 먼저 넣습니다.

질문 4

칸끼리 계산 관계가 있는 양식이 있나요?

금액 = 수량 × 단가, 시작일 ≤ 종료일 같은 것. 있으면 "계산 확인"을 앞당깁니다.

질문 5

응답자들이 줄을 숨기거나 취소선으로 지우는 습관이 있나요?

취소선은 "뺀다"로 볼지, 그냥 넣고 표시만 할지 정해야 합니다.

질문 6

한 번 취합할 때 규모는 어느 정도인가요?

파일 몇 개, 줄 몇 개 정도인지. "원본과 나란히 보기" 같은 화면을 얼마나 빠르게 만들어야 하는지 정합니다.
