내보내기: 받을 파일 고르기

제출처 목록이 있는 양식은 제출처별 파일(zip)과 공용 파일 1개 중에서 고릅니다. 위의 단추로 양식 구조를 바꿔 보고, 창 안의 두 선택지를 눌러 보세요. 오른쪽 엑셀 화면이 함께 바뀝니다.

파일마다 지사명이 미리 들어가 있고 잠겨 있어요. 취합할 때 누가 냈는지 틀릴 일이 없어요.

공용 파일 1개

모두에게 같은 파일을 보내요. 작성자가 지사명 칸에서 자기 지사를 골라요.

⚠ 빈칸채우기형은 공용 파일이면 다른 지사 칸이 잠기지 않아요. 다른 지사 칸에 적은 값은 취합할 때 쓰지 않고 알림으로 알려 드려요. 지사별 파일을 권해요.
시트 모으기형은 파일 속성으로만 지사를 알아내서 지사별 파일로만 만들 수 있어요.
