# 한국지역난방공사 조직 데이터 (제출처 트리 선택용)

생성 파트 ⑤ 지사/기관 패널에서 **트리를 보고 체크해서 제출처 목록(`org.orgs`)을 채우는** 기능에 쓰는 데이터다.

| 파일 | 용도 |
|---|---|
| `kdhc-org.json` | **프로그램이 읽는 파일.** 본사·지사 두 갈래 트리 |
| `kdhc-org.csv` | 사람이 엑셀로 확인하는 한 줄 목록 (같은 내용) |
| `kdhc-org.txt` | 눈으로 보는 트리 |

- 출처: kdhc.co.kr 조직도(본부 배치) + 임직원검색 전체 목록(부서명). 기준일은 JSON의 `fetchedAt`.
- 갱신: `python3 scripts/fetch-kdhc-org.py`. 조직 개편으로 본부·지사 배치가 바뀌면 스크립트 위쪽 `HQ`·`BRANCHES`만 고친다. 배치 안 된 부서가 생기면 스크립트가 멈추고 이름을 알려준다.

## 구조

```
본사 (구분, 선택 불가)
├─ 사장 직속 (묶음, 선택 불가) > 임원실, 비서부
├─ 상임감사위원 (묶음, 선택 불가) > 감사실 > 부
├─ 기획본부 > 처·실 > 부,  경영지원본부 > 처·센터 > 부
├─ GX본부 > 처 > 부
├─ 안전기술본부 > 처 > 부 > 과,  건설본부 > 처 > 부
└─ 기타 (묶음, 선택 불가) > 교육팀, 노동조합, 경영전문위원
지사 (구분, 선택 불가)
└─ 지사·사업소 19곳 > 부 > 과   (bonbu: 관할 본부)
```

- 본사 571명 / 지사 1,524명 (외부·파견 부서명 5개 제외).
- 지사 19곳 = 지사 15 + 사업소 4(고양·분당·김해·수원). 수원사업소만 건설본부 관할, 나머지는 안전기술본부.
- 지사의 `과`(운영1~4과, 운영지원과)는 교대조 단위라 양식 제출처로는 잘 쓰지 않는다. 기본은 접어 둔다.

## JSON 형식

```ts
interface OrgData {
  version: 1;
  fetchedAt: string;                       // 'YYYY-MM-DD'
  source: string;
  categories: { id: 'hq' | 'branch'; name: '본사' | '지사' }[];
  tree: OrgNode[];                         // [본사 루트, 지사 루트]
}

interface OrgNode {
  id: string;          // 전체 이름. 예: '강남지사 운영1부'. 트리 안에서 유일. ★ 제출처 이름으로 그대로 쓴다
  name: string;        // 화면에 보일 짧은 이름. 예: '운영1부'
  type: '구분' | '묶음' | '본부' | '처' | '실' | '센터' | '지사' | '사업소' | '부' | '과' | 'TF' | '관' | '팀' | '기타';
  category: 'hq' | 'branch';
  selectable: boolean; // false = 구분·묶음(실제 조직 아님). 체크박스 없이 펼치기만
  level: number;       // 0 = 본사/지사 루트
  headcount: number;   // 직속 인원
  total: number;       // 하위 포함 인원 (화면에 '113명'처럼 표시용)
  leaf: boolean;
  bonbu?: string;      // 지사만. 관할 본부
  children: OrgNode[];
}
```

## 선택 규칙 (구현 쪽에서 지킬 것)

1. **고른 노드의 `id`를 그대로 `org.orgs`에 넣는다.** 순서는 트리 순서(위→아래).
2. 체크는 노드마다 따로다. **상위를 체크해도 하위가 자동으로 들어가지 않는다.** "강남지사"를 고르면 제출처는 강남지사 1곳이다.
   - 하위를 한꺼번에 고르려면 노드 옆 "하위 모두" 버튼을 둔다(그 노드의 바로 아래 선택 가능한 자식 전부 체크).
   - 상위 노드에는 "하위 n개 선택됨" 배지를 보여 접힌 상태에서도 알 수 있게 한다.
3. `selectable: false` 노드는 체크박스를 그리지 않는다.
4. 빠른 선택 버튼(권장):
   - **지사 전체** → 지사 루트의 자식 19곳
   - **본사 처·실 전체** → 본사에서 type이 처·실·센터인 노드
   - **선택 해제**
5. 검색창: `name`·`id` 부분 일치. 맞는 노드와 그 조상만 펼쳐 보인다.
6. 트리로 고른 뒤에도 기존 붙여넣기 목록과 합쳐진다(중복 제거). 트리에 없는 이름(외부 기관 등)은 직접 추가할 수 있어야 한다.
7. 제출처를 부르는 말(`org.label`)은 고른 노드로 추천만 한다: 모두 지사·사업소면 '지사', 그 외 섞이면 '부서'. 사용자가 바꿀 수 있다.

## 예시

```jsonc
// tree[1] = 지사 루트, children[3] = 강남지사
{ "id": "강남지사", "name": "강남지사", "type": "지사", "category": "branch",
  "selectable": true, "level": 1, "headcount": 1, "total": 135, "leaf": false,
  "bonbu": "안전기술본부",
  "children": [
    { "id": "강남지사 고객지원부", "name": "고객지원부", "type": "부", "level": 2,
      "headcount": 15, "total": 15, "leaf": true, "children": [] }
    // ...
  ] }
```

"지사 전체"를 누르고 본사에서 `기획처`를 더 체크하면:

```json
{ "mode": "preset", "label": "부서",
  "orgs": ["기획처", "중앙지사", "동탄지사", "대구지사", "…", "수원사업소"] }
```
