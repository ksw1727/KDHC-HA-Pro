# 04. AI로 만들기

> 담당 코드: `src/ai/`(화면), `tools/ai/`(연결 서버·AI 설명서·OpenAI SDK 엔진·비교 시험), `tools/moa.ts`(AI용 도구)
> 2026-10-21 처음 만듦. 결과를 보며 고쳐 나가는 기능이라 이 문서도 함께 바꾼다.

## 1. 하는 일

사용자가 **받고 싶은 것을 말로** 적으면, AI(OpenAI Agents SDK)가 이 프로그램 규칙대로 양식 정의(`form.json`)를 만든다.
사람은 미리보기를 보고 [엑셀 내보내기] 또는 [패널에서 고치기]만 누른다. 구조 6종이나 설정 용어를 몰라도 된다.
AI는 우리 검사기를 통과한 양식만 넘기므로 취합이 의도대로 된다.

1차 범위는 **양식 만들기**까지다. 취합은 지금 [취합하기] 화면 그대로 쓴다(회신 내용은 AI로 보내지 않는다).

## 2. 구조

```
[AI로 만들기 화면] ──POST /api/ai/chat──▶ [연결 서버: vite 개발 서버에 붙은 플러그인]
                                         @openai/agents Agent + 함수 도구 (tools/ai/openaiAgent.ts)
                                         moa 도구: tools/moa.ts를 node 한 파일로 묶음 (~/.hanan-moa/ai/moa.mjs)
                                         작업 폴더 ~/.hanan-moa/ai/<대화ID>/
                                           form.json (AI가 만든 양식), openai-history.json (대화 기록), source/ (올린 엑셀)
                 ◀── NDJSON 이벤트 ──── chat · status · text · form · error · done
```

- 연결 서버는 `npm run dev`(또는 `npm run preview`) 서버 안에서만 돈다. HTML 파일 하나(`dist/index.html`)로 열면 "AI 연결 서버가 꺼져 있어요"가 보이고 나머지 화면은 그대로 쓴다.
- 화면이 연결을 끊으면([멈추기]·창 닫기) AI도 멈춘다.
- `.env.local`의 `OPENAI_API_KEY`가 있을 때 켜진다(`.env.example` 참고). 없으면 화면에 "OpenAI API 키가 없어요"를 보여 준다. 모델은 화면에서 `gpt-6.1-sol`·`gpt-6-luna` 중 고른다(브라우저에 기억). 시스템 프롬프트 버전은 `MOA_OPENAI_PROMPT`(A·B·C, 기본 B — 비교 시험 결과 2026-10-22).
- 작업 폴더 위치는 `MOA_AI_HOME`으로 바꿀 수 있다.
- 개발 서버에서 `src/`·`tools/`의 코드를 고치면 다음 대화에서 moa 도구를 다시 묶는다(서버를 다시 켤 필요 없음).
- 엑셀 내보내기는 브라우저의 `crypto.subtle`을 쓰므로 https 주소나 localhost에서 열어야 한다. 다른 기기에서 열 때는 https로 연다(예: `tailscale serve`). 실패하면 양식 카드에 이유를 보여 준다.

## 3. AI가 할 수 있는 것 (제한)

| 도구 | 쓰기 범위 |
|---|---|
| 셸 없음. 함수 도구 `moa`(command·args) · `read_file`(작업 폴더 안) · `write_file`(form.json만, JSON 검사) | form.json |

> 2026-10-22: `claude -p`·`codex exec` 엔진은 뺐다. OpenAI API만 쓴다.

`moa` 명령:
- `moa new <구조>`: 구조별 시작 양식 (`newSchema`)
- `moa check`: 계약 검사(`validateSchema`) → 내보내기 전 검사(`validateForExport`). "통과"가 나올 때까지 고친다
- `moa preview`: 빈 양식 엑셀 모양을 글로 (`layoutSheet`)
- `moa orgs [검색어]`: 한난 조직 이름 찾기 (`kdhcOrg`)
- `moa read-excel <파일>`: 올린 엑셀을 글로 (`tools/excelDump.ts`: 칸 값·수식·병합·입력 규칙(같은 규칙은 묶음)·채우기 색·빈 칸·메모, 매크로·조건부 서식·그림·다른 시트 참조·한난MOA에 없는 함수)

AI 설명서(`tools/ai/AGENTS.md`)에 구조 고르는 법, 양식 정의 요점, 작성처 규칙, 쉬운 말로 답하는 법을 적는다.

**숫자 칸 물어보기** (2026-10-22): 숫자 칸이 있는데 사용자가 단위·소수 자리를 말하지 않았으면, AI는 기본값(쉼표 켬, 사람·건수·금액 소수 0, 비율 1, 측정값 2)으로 먼저 만들고 답 끝에 "숫자 칸은 이렇게 해 두었어요" 목록으로 칸마다 단위·소수 자리·쉼표를 알리며 모르는 단위를 묻는다. 사용자가 답하면 그 칸을 고친다. 이 서식은 빈 양식, 취합 결과의 같은 틀 시트·지사별 시트에 모두 쓰인다.

시스템 프롬프트 (`tools/ai/prompts.ts`):

| 버전 | 내용 |
|---|---|
| A | AGENTS.md + 도구 이름 안내 |
| B | A + 엑셀 양식 스킬 `tools/ai/skills/excel-form.md` (Anthropic xlsx 스킬의 원칙 — 요구 글자 그대로, 알맞은 칸 종류, 입력 칸 읽는 법, "검사 통과 ≠ 요구대로" — 를 한난MOA에 맞게) |
| C | B + `tools/ai/skills/examples.md` (잘 만든 예시 3개, 끝내기 전 점검표) |

비교 시험: `npx vite-node tools/ai/eval/run.ts -- --reps 2` → `tools/ai/eval/out/results.json`. 시나리오 6개(`tools/ai/eval/scenarios.ts`)를 기계 채점한다.

## 4. 화면

- 위쪽 메뉴 맨 앞 [AI로 만들기] (처음 열면 이 화면). 위쪽 메뉴는 [AI로 만들기]·[취합하기] 두 개.
- **화면 = 대화(약 80%) + 오른쪽 설정 패널(①~⑤만)**. 미리보기는 대화 속 양식 카드에만 있고, 패널과 연결된 마지막 카드에는 "설정 패널과 연결됨" 표시가 붙는다(자세한 규칙은 `02-generator.md` 2장 "화면 위치").
- 빈 대화: 안내 문장 + 예시 4개(누르면 입력칸에 들어감).
- 보내면 AI가 하는 일을 한 줄로 보여 준다("양식 검사 중", "엑셀 모양 확인 중"). [멈추기]로 멈출 수 있다.
- 양식이 오면 카드: 제목 · 구조 · 제출처 한 줄 · 검사 결과 + 빈 양식 미리보기(빌더와 같은 표) + [패널에서 고치기] [엑셀 내보내기] [양식 파일 저장].
  - 고칠 곳이 있으면 목록을 보여 주고 [엑셀 내보내기]를 막는다.
  - 내보내면 지사에 보낼 안내문을 보여 준다.
- 이어서 말하면(예: "교육비는 빼 줘") 같은 `form.json`을 고친다.
- **대화는 한 작업이 끝날 때까지 이어진다.** 빌더 패널을 켜고 끄거나 취합하기에 다녀와도, 새로고침해도 그대로다(브라우저에 저장). 지우는 것은 [새 대화]를 눌러 확인했을 때뿐이다.
- **패널과 연동**: 오른쪽 패널에서 그 양식을 고치면(고칠 때마다, `hanan-moa:form-edit`) 마지막 양식 카드가 바로 그 양식으로 바뀌고 "패널에서 고침" 표시가 붙는다. 패널에서 고치는 중인 양식은 계약에 덜 맞아도(예: 빈 지사 목록) 미리보기를 보여 주고 고칠 곳으로 알린다. 다음에 AI에게 말하면 고친 양식을 함께 보내 거기서 이어 고친다(AI 작업 폴더의 양식과 같으면 다시 보내지 않음).
  - AI가 쓴 설명은 그때 양식 기준이라 고칠 수 없으므로, 카드 아래 **"패널에서 고친 내용"** 상자에 AI가 만든 양식과 달라진 점을 문장으로 보여 준다(`src/ai/formDiff.ts`: 제목·구조·안내·제출처 추가/뺌·항목 추가/뺌/이름·필수·서식). 같은 문장을 다음 말과 함께 AI에게도 넘긴다.
  - 원래 양식을 모르는 대화(이전 화면에서 바뀐 카드)는 `GET /api/ai/form?chatId=`로 AI 작업 폴더의 양식을 가져와 비교한다.
- AI 답의 `**굵게**`는 굵은 글자로 보여 준다.

## 5. 쓰던 엑셀 올리기

- [엑셀 올리기] 버튼 또는 대화 영역에 끌어다 놓기. .xlsx·.xlsm·.xls, 10MB 이하, 한 번에 5개까지. 다른 파일은 이유를 알리고 뺀다. 파일만 넣고 보내면 "올린 엑셀 양식으로 같은 양식을 만들어 주세요."로 보낸다.
- 연결 서버는 파일을 작업 폴더 `source/`에 두고 AI에게 위치를 알린다. AI는 `moa read-excel`로 읽고 셋 중 하나로 판단한다(설명서 "쓰던 엑셀 올리기").
  - **① 그대로 만들기**: 6가지 구조로 옮길 수 있으면 같은 모양으로 (머리글·순서·선택지·필수·안내를 살림).
  - **② 바꿔서 만들기**: 일부만 안 맞으면 되는 부분은 만들고 "그대로 옮기지 못한 것 N가지: ✕ 원본 → 바꾼 방법"을 모두 알림 (없는 함수·다른 시트 참조 → 선택 목록·취합 합계, 조건부 서식 → 입력 규칙, 병합 → 자유 제작형, 꾸밈 그림 → 뺌, 참조 없는 여러 시트 → 한 시트).
  - **만들 수 없음**: 매크로로 돌아가는 양식, 시트끼리 값을 주고받는 양식, 칸으로 나눌 수 없는 서술·그림 보고서, 제출처마다 칸 위치가 다른 양식, 읽을 수 없는 파일. 양식을 만들지 않고 첫 줄 "이 양식은 한난MOA로 다시 만들 수 없어요."와 이유·바꾸는 방법을 알린다. 화면은 이 답을 붉은 테두리로 보여 준다. 억지로 비슷하게 만들어 취합이 틀어지는 것을 막기 위해서다.
