"어떤 구조로 만들지" 고민하지 않게 하는 화면

구조 이름(목록형, 표형 등)만으로는 결과를 떠올리기 어렵습니다. 그래서 배포 양식이 지사를 거쳐 취합본이 되는 과정을 짧은 움직임으로 보여주고, 그래도 모르겠으면 질문에 답해서 고를 수 있게 했습니다. 아래 목업은 실제로 눌러볼 수 있습니다.

1카드에서 미리 보기구조 4개를 카드로 나란히 보여줍니다. 카드마다 결과 모양이 작게 반복 재생되고, 쓰임새 예시가 붙어 있습니다.
2크게 보기 (3컷 이야기)카드를 누르면 아래 큰 화면에서 "① 배포 양식 → ② 지사가 작성 → ③ 취합본"이 차례로 재생됩니다. 마지막에 "취합하면 이렇게 돼요" 한 줄 설명이 붙습니다.
3질문으로 고르기"잘 모르겠어요"를 누르면 질문 1~2개로 알맞은 구조를 추천하고, 해당 카드에 '추천' 표시를 합니다.

이 화면에서 지키는 원칙
  • 구조 이름보다 결과 모양과 예시("교육 참가자 명단", "학년별 인원표")를 먼저 보여줍니다.
  • 모든 구조는 같은 3컷 이야기(배포 → 작성 → 취합)로 보여줘 서로 비교하기 쉽게 합니다.
  • 움직임은 6초 안에 끝나고 반복합니다. [멈춤]과 [다시 보기]를 항상 둡니다.
  • 컴퓨터에 "동작 줄이기"가 켜져 있으면 움직이지 않고 3컷을 한꺼번에 보여줍니다.
  • 구조를 바꾸면 지워지는 항목을 미리 알려 줍니다(PRD 2.2 "이동 불가한 항목은 확인 창").

만드는 방법 (개발자 1 메모)

  • 동영상이나 GIF가 아니라 실제 화면 요소(작은 표)를 순서대로 나타나게 하는 방식입니다. 파일 용량이 거의 없고, 한 파일 빌드(index.html)에 그대로 들어가며, 글자가 선명합니다.
  • 부품은 두 개입니다. StructurePicker(카드 4개, 질문, 시작 버튼)와 StructureStory(3컷 이야기, 크게/작게 공용)입니다. 이야기 내용은 구조별 데이터 표 하나로 관리해서, 나중에 구조가 늘어나도 데이터만 추가하면 됩니다.
  • 움직임은 CSS 전환과 0.5초 간격 타이머로만 만듭니다(추가 라이브러리 없음). 화면 밖에 있거나 [멈춤]을 누르면 타이머를 멈춥니다.
  • 질문 흐름: "여러 줄" → (지사 정보도? 아니요 = 목록형 / 네 = 혼합형), "정해진 표 숫자" = 표형, "빈칸만" = 빈칸채우기형.
  • PRD 반영 위치: 02-generator.md 2.1 시작 화면의 "구조 선택(각각 작은 그림 예시)"을 이 화면으로 구체화합니다.
